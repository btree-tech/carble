# ロールと権限

## ユーザーストーリー（Why）

- 研究者が、Google アカウントでユーザー登録するだけで使い始めることで、誰でも手軽にカードでデータを蓄積したい（[CESCHI-204](https://kinako.atlassian.net/browse/CESCHI-204)）
  - 研究者が、自分が閲覧できるプロジェクトだけを一覧することで、他の人のデータと混ざらずに作業したい（[CESCHI-204](https://kinako.atlassian.net/browse/CESCHI-204)）
- プロジェクトのオーナーが、他のユーザーをプロジェクトに招待することで、共同でカードを編集したい（[CESCHI-212](https://kinako.atlassian.net/browse/CESCHI-212)）
  - 招待されたユーザーが、招待を承認または拒否することで、参加するプロジェクトを自分で選びたい（[CESCHI-212](https://kinako.atlassian.net/browse/CESCHI-212)）
- オーナーが、インポートによる一括の上書きを自分だけに限ることで、編集者が誤ってデータを失う心配なく共同作業したい（[CESCHI-227](https://kinako.atlassian.net/browse/CESCHI-227)）

## 外部仕様（What）

ロールはプロジェクトごとに決まる。同じユーザーが、あるプロジェクトではオーナー、別のプロジェクトでは編集者になる。

| ロール | 説明 | 主な操作 |
|---|---|---|
| オーナー | プロジェクトを作成したユーザー。プロジェクトに 1 人。[プロジェクト一覧](../pages/project-list.md)の列名は「オーナー」、[プロジェクト設定](../pages/project-settings.md#ユーザー管理)のユーザー管理の「権限」は「管理者」と表示する | 編集者の操作すべて、インポート、ユーザーの招待・削除、プロジェクトの削除 |
| 編集者 | オーナーの招待を承認したユーザー。ユーザー管理の「権限」は空欄 | カード・項目の追加・編集・削除・複製、プロジェクト名の変更、エクスポート、印刷 |
| 招待中のユーザー | オーナーに招待され、まだ承認していないユーザー。ユーザー管理の「ステータス」に「招待中」と表示する | プロジェクト一覧での招待の承認・拒否のみ |

本書では、オーナーと編集者をまとめて「メンバー」と呼ぶ。

### ログイン

- [ログイン画面](../pages/login.md)以外の画面は、ログインしているユーザーだけが使える
  - **IF** ログインせずにログイン画面以外を開いた場合、ログイン画面に遷移する
- **WHERE** ログインしているがユーザーIDを登録していない場合、ログイン画面以外のどの画面を開いても[ユーザー登録](../pages/user-register.md)に遷移する

### プロジェクトへのアクセス

- **WHERE** プロジェクトのメンバーの場合、そのプロジェクトの画面（テーブルビュー・カード入力ビュー・グリッドビュー・カード印刷ビュー・プロジェクト設定）を表示する
- **IF** メンバーでないプロジェクトの画面を開いた場合、エラー画面（404）を表示する
  - 招待中のユーザーも、承認するまではメンバーでないものとして扱う
- **WHERE** オーナーの場合、[プロジェクト設定](../pages/project-settings.md)に「インポート」「ユーザー管理」「プロジェクト削除」のタブを表示する
- **WHERE** 編集者の場合、プロジェクト設定には「全般」のタブだけを表示する
- オーナーを変えたり、オーナーをプロジェクトから外したりはできない
- 編集者は、自分でプロジェクトから抜けられない。外すのはオーナーだけができる

## 補足情報

### 実装との乖離

- 画面では編集者にインポートを見せないが、サーバー側ではインポートのオーナー判定が効いておらず、編集者でも画面を通さずに送ればインポートできる（[security-review/report.md](../../plans/security-review/report.md) の指摘 7）
- プロジェクトの ID の書き方を変えると、メンバーかどうかの確認を通らずに API を呼べる。ほかにも認可の不備がある（[security-review/report.md](../../plans/security-review/report.md) の指摘 1・3・4・6・8）
- 編集者にはプロジェクト設定の「インポート」「ユーザー管理」「プロジェクト削除」のタブを表示しないが、URL を直接開くとその画面を表示する。インポートはできてしまい（上記の指摘 7）、ユーザー管理ではメンバーの一覧（招待中のユーザーを除く）が見える。招待・ユーザーの削除・プロジェクトの削除のボタンも表示するが、押してもサーバーが受け付けない
