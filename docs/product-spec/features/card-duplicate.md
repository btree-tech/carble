# カードの複製

対象の画面: [テーブルビュー](../pages/table-view.md)、[カード入力ビュー](../pages/card-view.md)、[グリッドビュー](../pages/grid-view.md)

## ユーザーストーリー（Why）

- 研究者が、似た内容のカードを複製して作ることで、同じ値を何度も入力せずに済むようにしたい（CESCHI-111、理由は推測）
- 研究者が、カード群を別のプロジェクトに複製することで、再編したカード群から新しいプロジェクトを作りたい（CESCHI-174）
- 研究者が、複製元と複製先のカードをたどることで、複製した後のカードの違いを確かめたい（CESCHI-175）

## 外部仕様（What）

### 複製の内容

- 複製すると、元のカードと同じ値・同じ画像を持つ新しいカードを作る
  - 新しいカードの ID は、複製先のプロジェクトのカードの ID の最大値の次から振る
  - 画像は、元のカードの画像とは別のファイルとして複製する（元のカードの画像を削除しても、複製したカードの画像は残る）
- 複製したカードは、元のカードを「複製元」として覚える
- 置く位置は次のとおり

| 操作 | 置く位置 |
|---|---|
| 直下に複製 | 元のカードのすぐ下。プロジェクトのカードの並び順を 1 から振り直す |
| 末尾に複製 | プロジェクトの末尾 |
| 別プロジェクトに複製、選択したカードの複製 | 複製先のプロジェクトの末尾。複数のカードは元の並び順の順に置く |

### 別のプロジェクトへの複製

- 複製先には、自分がメンバーになっている（招待を受けている途中のものを除く）他のプロジェクトを更新日時の新しい順に一覧し、その下に「新しいプロジェクト」を表示する
  - **WHERE** インポート中のプロジェクトの場合、「インポート中」と表示し、選べない
- 項目は名前で対応づける
  - **WHERE** 複製先に同じ名前の項目が無い場合、その項目を複製先の末尾に追加する
    - 追加した項目は、複製元で非表示にしていても表示する
- **WHEN** 「新しいプロジェクト」を選ぶと、「無題のプロジェクト」という名前のプロジェクトを作り、そこに複製する

### 複製元と複製先

- **WHERE** カードに複製元がある場合、「複製元カードを表示」で複製元のカードの[カード入力ビュー](../pages/card-view.md)に遷移する
  - 複製元が別のプロジェクトでも遷移する
  - **IF** 複製元のカードが削除されている場合、「複製元カードを表示」を選べない
- **WHERE** カードを複製したことがある場合、「複製先カードを表示」で複製先の一覧のダイアログを開く
  - 一覧には「（プロジェクト名） - ID: （ID）」の形で複製先のカードを表示する
  - **WHEN** 複製先を選ぶと、そのカードの[カード入力ビュー](../pages/card-view.md)に遷移する

### 複製した後の画面

- 複製すると「複製しました」と表示し、次のとおり遷移する

| 画面 | 操作 | 遷移先 |
|---|---|---|
| テーブルビュー | 直下に複製、末尾に複製 | 遷移しない |
| テーブルビュー | 別プロジェクトに複製（既存のプロジェクト） | 複製先の[テーブルビュー](../pages/table-view.md) |
| テーブルビュー | 別プロジェクトに複製（新しいプロジェクト） | 複製先の[テーブルビュー](../pages/table-view.md) |
| カード入力ビュー | 直下に複製、末尾に複製 | 複製したカードの[カード入力ビュー](../pages/card-view.md)。今の並び替えと検索の条件を引き継ぐ |
| カード入力ビュー | 別プロジェクトに複製（既存のプロジェクト） | 複製したカードの[カード入力ビュー](../pages/card-view.md) |
| カード入力ビュー | 別プロジェクトに複製（新しいプロジェクト） | 複製したカードの[カード入力ビュー](../pages/card-view.md) |
| 選択したカードの複製 | 既存のプロジェクト | 複製先の[テーブルビュー](../pages/table-view.md) |
| 選択したカードの複製 | 新しいプロジェクト | 複製した最初のカードの[カード入力ビュー](../pages/card-view.md) |

## 補足情報

### 実装との乖離

- 「新しいプロジェクト」に複製すると、作ったプロジェクトにオーナーが設定されない。誰もメンバーでないため、遷移した先は空の画面になる（エラー画面は表示しない）。プロジェクト一覧にも表示されない（[ISSUES.md](../../ISSUES.md#新しいプロジェクトに複製するとプロジェクトを開けない)、[security-review/report.md](../../plans/security-review/report.md) の指摘 3）
- カードを削除して並び順の数字が飛んでいると、「直下に複製」をしたカードがすぐ下に入らず、並び順がほかのカードと重なる（[ISSUES.md](../../ISSUES.md#並び順が飛んでいると直下に追加直下に複製がすぐ下に入らない)）
- 別のプロジェクトのカード入力ビューから「複製元カードを表示」で移ると、移った先のカードの値は表示するが、カードのメニュー（「複製元カードを表示」「複製先カードを表示」を選べるか）は移る前のカードのままになる（[ISSUES.md](../../ISSUES.md#別のプロジェクトのカード入力ビューから移るとカードのメニューが移る前のカードのままになる)）
- 複製先のプロジェクトがメンバーになっているプロジェクトかどうかを、サーバー側で確かめていない（[security-review/report.md](../../plans/security-review/report.md) の指摘 3）
