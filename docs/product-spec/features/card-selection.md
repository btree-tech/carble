# カードの選択と一括操作

対象の画面: [テーブルビュー](../pages/table-view.md)、[グリッドビュー](../pages/grid-view.md)

## ユーザーストーリー（Why）

- 研究者が、複数のカードを選んでまとめて削除・複製することで、カード群の整理や再編を手早く行いたい（CESCHI-174）

## 外部仕様（What）

### 選択

- カードごとに選択のチェックボックスを表示する（グリッドビューでの表示は [グリッドビュー](../pages/grid-view.md#選択) を参照）
- テーブルビューの見出しに、すべてのカードを選ぶチェックボックスを表示する
  - **WHEN** 見出しのチェックボックスを選ぶと、表示しているすべてのカードを選ぶ
  - **WHEN** 1 件以上選んでいるときに見出しのチェックボックスを押すと、選択をすべて外す
  - **WHILE** 一部のカードだけを選んでいる間は、見出しのチェックボックスを「一部選択」の表示にする
- **WHEN** テーブルビューで別の画面に移るか、カードの一覧が変わる（カードの追加・複製・削除、並び替え、検索）と、選択を外す
- グリッドビューでは、別の画面に移っても選択を保つ
  - **WHEN** グリッドビューでカードの一覧が変わると、一覧から無くなったカードだけを選択から外す

### 一括操作

- **WHILE** 1 件以上選んでいる間は、「（件数）件選択中」「複製」「削除」のボタンを表示する
  - **WHEN** 「（件数）件選択中」を押すと、選択をすべて外す
- **WHEN** 「複製」を押すと、複製先のプロジェクトの一覧を開く（[カードの複製](card-duplicate.md#別のプロジェクトへの複製)）
  - 今開いているプロジェクトは一覧に含めない
  - **WHEN** プロジェクトを選ぶと、選んだカードすべてをそのプロジェクトの末尾に複製し、「複製しました」と表示して、そのプロジェクトの[テーブルビュー](../pages/table-view.md)に遷移する
  - **WHEN** 「新しいプロジェクト」を選ぶと、新しいプロジェクトを作って選んだカードすべてを複製し、「複製しました」と表示して、複製した最初のカードの[カード入力ビュー](../pages/card-view.md)に遷移する
- **WHEN** 「削除」を押すと、「削除してよろしいですか？」と確認する
  - **WHEN** 確認すると、選んだカードすべてを削除する

## 補足情報

### 実装との乖離

- 一括削除では、完了メッセージ（「削除しました」）を表示しない
- グリッドビューで選んだカードを、ほかの画面（テーブルビューなど）で削除してからグリッドビューに戻ると、削除したカードが選択に残ったまま（「（件数）件選択中」の件数に数える）になる。グリッドビューを表示している間に一覧が変わったときだけ、選択から外す
- 「新しいプロジェクト」に複製すると、作ったプロジェクトにオーナーが設定されず、遷移した先は空の画面になる（エラー画面は表示しない）（[ISSUES.md](../../ISSUES.md#新しいプロジェクトに複製するとプロジェクトを開けない)、[カードの複製](card-duplicate.md#実装との乖離)）
