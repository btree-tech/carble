# インポート・エクスポート

対象の画面: [プロジェクト設定](../pages/project-settings.md)（エクスポート・インポート）、[プロジェクト一覧](../pages/project-list.md#新規プロジェクト)（ファイルをインポートして新規プロジェクト）

## ユーザーストーリー（Why）

- 研究者が、表計算ソフトで作ったデータや画像をまとめて取り込むことで、既存の資料のデータを一度に Carble に移したい（推測、確信度: 高）
  - 研究者が、エクスポートしたファイルをそのまま取り込めることで、表計算ソフトで編集してから戻したい（推測、確信度: 中）
  - 研究者が、大きなファイルでもタイムアウトせずに取り込みたい（CESCHI-106、CESCHI-156）
  - 研究者が、インポートの完了を自分で再読み込みせずに知りたい（CESCHI-191）
- オーナーが、上書きを明示的に選ぶことで、意図せずカードの内容を失わないようにしたい（CESCHI-227、CESCHI-232）
- 研究者が、プロジェクトのデータと画像をまとめて書き出すことで、バックアップや他のツールでの利用に使いたい（推測、確信度: 高）
- 研究者が、インポートやエクスポートで、資料の順番（並び順）を保ちたい（CESCHI-179）

## 外部仕様（What）

### エクスポート

- プロジェクトのデータを zip ファイルでダウンロードする
  - ファイル名は「（プロジェクト名）-（年月日時分秒）.zip」とする（例: `調査票-20261027153000.zip`）。日時は、エクスポートを押したときの利用者の端末の日時とする
- zip には、エクセルのファイル 1 つと、カードの画像のファイルを入れる
- エクセルのファイル名は「（プロジェクト名）.xlsx」とする
  - プロジェクト名にファイル名に使えない文字（`\ / : * ? " < > |`）がある場合、`_` に置き換える
- エクセルの 1 行目は見出しとし、「ID」、すべての項目（項目の並び順。非表示の項目も含む）、「画像ファイル」の列とする
- 2 行目以降に、カードを並び順の順に 1 行ずつ書く
  - 「画像ファイル」の列には、そのカードの画像のファイル名を、追加した順に改行で区切って書く
- 画像のファイル名は「（カードの ID）-（画像の番号）.（拡張子）」とする（例: `1-12.jpeg`）
  - 画像の番号はシステム全体で画像ごとに振られる番号で、カードの中の連番ではない
  - 拡張子は、画面から添えた画像は画像の形式による。インポートで取り込んだ画像は、取り込んだファイルの拡張子のままとする
  - 画像はフォルダに分けず、zip のいちばん上に置く
- **IF** 画像のファイルがサーバーに無い場合、その画像は zip に入れない（[実装との乖離](#実装との乖離)）

### インポート

- インポートできるのは、エクセル（xlsx）、CSV（UTF-8）、zip のファイルとする
- アップロードしたファイルは、すぐには取り込まず、毎分 0 秒に動く処理が順に取り込む
  - 取り込むのは、すべてのプロジェクトを通じて、アップロードの古い順に 1 件ずつとする。前のインポートが終わるまで、次のインポートは始めない
- **WHERE** エクセル・CSV の場合、最初のシートの表を取り込む
  - 1 行目を項目名、2 行目以降をカードとする
  - 表の途中の空の行も、値が空のカードとして取り込む
  - **WHERE** 項目名がプロジェクトに無い場合、その項目を末尾に追加する
  - **WHERE** プロジェクトにある項目がファイルに無い場合、その項目の値は変えない
  - 「ID」の列は項目にせず、カードの ID として扱う（下の表）
  - 「画像ファイル」の列は項目にしない（エクセル・CSV の場合は列の値も使わない）
  - 新しいカードは、ファイルの行の順に、プロジェクトの末尾に置く
- **WHERE** zip の場合、中のエクセルまたは CSV のファイル 1 つを、上と同じように取り込む
  - エクセル・CSV のファイルは、名前が `.xlsx`・`.csv`（小文字）で終わるものを探す。macOS が作る `__MACOSX` フォルダの中のファイルは無視する
  - **WHERE** 「画像ファイル」の列がある場合、各行のカードの画像を、列に書いたファイル名の画像に置き換える
    - ファイル名は、zip のいちばん上からのパスで書く
    - ファイル名は、空白または改行で区切って複数書ける（[実装との乖離](#実装との乖離)）
    - **WHERE** 列が空の場合、そのカードの画像を消す
  - **WHERE** 「画像ファイル」の列が無い場合、画像は変えない
- 「ID」の列は、「同じIDのカードを上書きする」のチェックで扱いが変わる

| 上書き | ID の値 | 取り込み方 |
|---|---|---|
| しない | どれでも | 新しいカードを作る（ID は振り直す） |
| する | 空 | 新しいカードを作る |
| する | 数字で、その ID のカードがある | そのカードの値を、行の値で上書きする。空のセルは値を空にする。並び順は変えない |
| する | 数字で、その ID のカードが無い | その ID で新しいカードを作る |

- 新しく振るカードの ID は、プロジェクトのカードとファイルの「ID」の列の、いちばん大きい数字の次から振る
- **IF** ファイルに次の誤りがある場合、何も取り込まず、結果をフォーマットエラーとし、次の内容を記録する

| 誤り | 記録する内容 |
|---|---|
| ID が数字でない行がある（上書きしない場合も確かめる） | 「`{行}`行目: IDは数字で入力してください」（行は見出しを除いて 1 から数える） |
| 「画像ファイル」の列に書いた画像が zip に無い | 「`{行}`行目: 画像ファイル(`{ファイル名}`)が存在していません」 |
| zip を展開できない | 「zipファイルの解凍に失敗しました」 |
| zip にエクセル・CSV が無い | 「zip内にエクセル/CSVファイルが含まれていません」 |
| zip にエクセル・CSV が 2 つ以上ある | 「zip内にエクセル/CSVファイルが複数含まれています」 |
| 表に行が無い | 「エクセル/CSVファイルに行が存在していません」 |
| 表に見出しの行しか無い | 「エクセル/CSVファイルにデータが存在していません」 |

  - 行ごとの誤り（ID・画像ファイル）は、すべての行を確かめ、見つけた誤りを 1 件 1 行で記録する

- **IF** 取り込みの途中で予期しないエラーが起きた場合、結果をシステムエラーとし、エラーの内容を記録する（[実装との乖離](#実装との乖離)）
- 結果は[プロジェクト設定のインポート履歴](../pages/project-settings.md#インポート)と、オーナーの[テーブルビュー](../pages/table-view.md#ヘッダー)に表示する

### インポート中の画面

- **WHILE** プロジェクトのインポートを待っている間・取り込んでいる間は、そのプロジェクトの画面に「インポート中です」のダイアログを表示し、カードを操作させない（[実装との乖離](#実装との乖離)）
  - 「現在、（アップロードした日時） にアップロードされた （ファイル名） を処理中です。」と表示する
  - 「再読み込み」ボタンで、インポートが終わったかを確かめる
  - 30 秒ごとに、インポートが終わったかを自動で確かめる
  - **WHEN** インポートが終わると、ダイアログを閉じてカードを表示する
  - 「ホームに戻る」ボタンで、[プロジェクト一覧](../pages/project-list.md)に遷移する
- **WHILE** インポート中は、そのプロジェクトを複製先に選べない（[カードの複製](card-duplicate.md#別のプロジェクトへの複製)）

## 補足情報

### 実装との乖離

- エクスポートのエクセルのファイル名で置き換えるのは、ファイル名に使えない文字のうち最初の 1 文字だけで、2 文字目以降は残る
- エクスポートのダウンロードが、サーバーのエラー（500）で失敗する。E2E の環境ではカードの枚数によらず失敗した。本番で起きるかは確かめていない（[ISSUES.md](../../ISSUES.md#エクスポートが失敗する)）
- 画像のファイルがサーバーに無い画像があると、エクスポートのダウンロードが終わらない（[ISSUES.md](../../ISSUES.md#画像のファイルが無いとエクスポートが終わらない)）
- 値が数値の 0 のセルは、空として取り込む
- BOM の無い UTF-8 の CSV は、日本語が文字化けする（見出しが既存の項目に当たらず、文字化けした名前の項目が増える）。BOM 付き（Excel の「CSV UTF-8」）は正しく取り込む（[ISSUES.md](../../ISSUES.md#bom-の無い-utf-8-の-csv-は文字化けする)）
- 0 バイトの CSV は、「行が存在していません」ではなく「エクセル/CSVファイルにデータが存在していません」になる
- 「画像ファイル」の列で、空白・改行が 2 つ以上続く、または末尾にある（Windows の改行を含む）と、システムエラーになる（[ISSUES.md](../../ISSUES.md#画像ファイルの列で空白が続くとシステムエラーになり途中まで取り込まれる)）
- 取り込みの途中でシステムエラーになっても、それまでに取り込んだ項目・カード・値・画像は元に戻さない（[ISSUES.md](../../ISSUES.md#画像ファイルの列で空白が続くとシステムエラーになり途中まで取り込まれる)）
- インポート中に、テーブルビュー以外のプロジェクトの画面（`/projects/:id/` 以下）を再読み込みしたり URL を直接開いたりすると、「インポート中です」のダイアログではなくエラー画面（409）を表示する（[ISSUES.md](../../ISSUES.md#インポート中にプロジェクトの画面を直接開くとエラー画面になる)）
- アップロードできるファイルの大きさは、画面の案内（600MB）ではなく、サーバーの前に置くリバースプロキシの設定（このリポジトリの外）で決まる
- インポートの「画像ファイル」の列に、展開したフォルダの外のファイルを書くと、サーバー上のファイルを取り込めてしまう（[security-review/report.md](../../plans/security-review/report.md) の指摘 2）
