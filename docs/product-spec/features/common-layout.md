# 画面共通（完了メッセージ・保存状態・エラー画面）

## ユーザーストーリー（Why）

- 研究者が、入力した内容を保存ボタンを押さずに残すことで、入力に集中したい（推測、確信度: 中）
  - 研究者が、保存中・保存済み・失敗を見分けることで、入力が確実に残ったか安心したい（推測、確信度: 高）
- 研究者が、操作が終わったことを画面で確かめたい（推測、確信度: 中）

## 外部仕様（What）

### 画面

- ブラウザのタイトルは「Carble」とする
- **WHERE** スマホ幅の場合、ボタンの一部は文言を省いてアイコンだけにする（各画面の仕様を参照）

### 保存状態のアイコン

- プロジェクトの画面で入力した値（プロジェクト名・カードの値・並び順）は自動で保存する。保存ボタンは無い
  - ユーザーIDと名前は自動で保存せず、「保存」ボタンで保存する（[ユーザー登録](../pages/user-register.md)・[設定（ユーザー）](../pages/user-settings.md)）
- [テーブルビュー](../pages/table-view.md)・[カード入力ビュー](../pages/card-view.md)・[グリッドビュー](../pages/grid-view.md)のヘッダーに、保存状態のアイコンを表示する
  - **WHILE** 保存中は、回転するアイコンを表示する
  - **WHEN** 保存が終わると、チェックのアイコンを表示する
  - **IF** 保存に失敗した場合、赤いエラーのアイコンを表示する

### 完了メッセージ

- **WHEN** 次の操作が完了すると、画面の隅に完了メッセージを表示する

  | 操作 | メッセージ |
  |---|---|
  | カードの追加 | 「追加しました」 |
  | カードの複製（選択したカードの複製を含む） | 「複製しました」 |
  | カードの削除（1 件ずつの削除） | 「削除しました」 |
  | スキャン（既存のカードに画像を追加） | 「スキャン完了」「ID: （カードのID）のカードに画像を追加しました」 |
  | スキャン（新しいカードを追加） | 「スキャン完了」「新しいカードを追加しました」 |
  | プロジェクトの削除 | 「プロジェクトを削除しました」 |

- 選択したカードの一括削除・項目の追加・画像の削除など、ほかの操作では完了メッセージを表示しない

### エラー画面

- **IF** 存在しない画面・権限のない画面を開いた場合、エラーの番号（404 など）を表示するエラー画面を表示する

## 補足情報

### 実装との乖離

- 削除の確認や画面の文言など、日本語の画面の中で、エラー画面だけ英語（Nuxt の標準のエラー画面）になる。表が空のときの「No items.」も英語のまま表示する
- 保存状態のアイコンを出す操作のほかは、操作に失敗しても何も表示しない（招待の承認・拒否、プロジェクトの作成、ユーザーIDと名前の保存、ユーザーデータの削除など）
