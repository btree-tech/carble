## 外部仕様（What）

### GET /api/projects/{projectId}/imports（インポートの一覧）

入力

| 場所 | 名前 | 型 | 必須 | 内容 |
|---|---|---|---|---|
| パス | projectId | 整数 | 必須 | プロジェクトの ID |
| クエリ | status | OPEN・IN_PROGRESS・DONE・ABORT・FORMAT_ERROR・SYSTEM_ERROR から 2 つ以上 | 任意 | そのどれかの状態のインポートに絞り込む |
| クエリ | unnotified | 真偽値 | 任意 | true なら結果を知らせていないインポートに絞り込む |
| クエリ | page | 整数 | 任意 | ページ（既定は 1） |
| クエリ | pageCount | 整数 | 任意 | 1 ページの件数（既定は 10） |

処理

| 条件 | 処理 |
|---|---|
| （常に） | プロジェクトのインポートを取得する |
| status がある | そのどれかの状態のインポートだけにする |
| unnotified が true | 結果を知らせていないインポートだけにする |
| （常に） | 登録の新しい順に並べ、page のページの pageCount 件を取る |

出力

| 状態 | 条件 | 本文 |
|---|---|---|
| 200 | （常に） | インポートの配列（items）、絞り込んだインポートの総数（total）、1 ページの件数（pageCount） |

エラー

| 状態 | 条件 |
|---|---|
| 400 | クエリが入力の形に合わない |

### POST /api/projects/{projectId}/imports（インポートの登録）

入力

| 場所 | 名前 | 型 | 必須 | 内容 |
|---|---|---|---|---|
| パス | projectId | 整数 | 必須 | プロジェクトの ID |
| 本文（multipart） | file | zip・CSV・エクセルのファイル | 必須 | インポートするファイル |
| 本文（multipart） | update | true・false | 任意 | true なら同じ ID のカードを上書きする |

処理

| 条件 | 処理 |
|---|---|
| （常に） | ファイルを保存し、インポートを取り込み待ち（OPEN）として登録する（取り込みはインポート・エクスポートの仕様） |
| update が true | 同じ ID のカードを上書きするインポートにする |

出力

| 状態 | 条件 | 本文 |
|---|---|---|
| 200 | （常に） | 登録したインポート |

エラー

| 状態 | 条件 |
|---|---|
| 422 | file が無いか、zip・CSV・エクセルのファイルでない |

### PUT /api/projects/{projectId}/imports/{importId}（インポートの結果を知らせたことの記録）

入力

| 場所 | 名前 | 型 | 必須 | 内容 |
|---|---|---|---|---|
| パス | projectId | 整数 | 必須 | プロジェクトの ID |
| パス | importId | 整数 | 必須 | インポートの ID |
| 本文（JSON） | notified | true | 必須 | 結果を知らせたこと |

処理

| 条件 | 処理 |
|---|---|
| （常に） | インポートに、結果を知らせた日時を記録する |

出力

| 状態 | 条件 | 本文 |
|---|---|---|
| 200 | （常に） | 記録したインポート |

エラー

| 状態 | 条件 |
|---|---|
| 404 | importId のインポートがプロジェクトに無い |
| 400 | 本文が入力の形に合わない |
