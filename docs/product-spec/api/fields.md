## 外部仕様（What）

### POST /api/projects/{projectId}/fields（項目の追加）

入力

| 場所 | 名前 | 型 | 必須 | 内容 |
|---|---|---|---|---|
| パス | projectId | 整数 | 必須 | プロジェクトの ID |
| 本文（JSON） | name | 文字列 | 必須 | 項目名 |

処理

| 条件 | 処理 |
|---|---|
| （常に） | 項目を項目の末尾に追加する |
| （常に） | プロジェクトの最終更新日時を更新する |

出力

| 状態 | 条件 | 本文 |
|---|---|---|
| 200 | （常に） | 追加した項目 |

エラー

| 状態 | 条件 |
|---|---|
| 400 | 本文が入力の形に合わない |
| 409 | プロジェクトに取り込み待ち・取り込み中のインポートがある |

### PUT /api/projects/{projectId}/fields（項目の並び替え）

入力

| 場所 | 名前 | 型 | 必須 | 内容 |
|---|---|---|---|---|
| パス | projectId | 整数 | 必須 | プロジェクトの ID |
| 本文（JSON） | （配列） | id・order の組の配列 | 必須 | プロジェクトの全項目の ID と並び順 |

処理

| 条件 | 処理 |
|---|---|
| （常に） | 各項目の並び順を送った値にする |
| （常に） | プロジェクトの最終更新日時を更新する |

出力

| 状態 | 条件 | 本文 |
|---|---|---|
| 204 | （常に） | なし |

エラー

| 状態 | 条件 |
|---|---|
| 400 | 本文が入力の形に合わない |
| 400 | 送った項目の数がプロジェクトの項目の数と違う |
| 400 | 送った並び順が重なっている |
| 409 | プロジェクトに取り込み待ち・取り込み中のインポートがある |

### PUT /api/projects/{projectId}/fields/{fieldId}（項目の変更）

入力

| 場所 | 名前 | 型 | 必須 | 内容 |
|---|---|---|---|---|
| パス | projectId | 整数 | 必須 | プロジェクトの ID |
| パス | fieldId | 整数 | 必須 | 項目の ID |
| 本文（JSON） | name | 文字列 | name・isVisible のどちらか | 新しい項目名 |
| 本文（JSON） | isVisible | 真偽値 | name・isVisible のどちらか | 項目を表示するか |

処理

| 条件 | 処理 |
|---|---|
| name がある | 項目名を name にする |
| isVisible がある | 項目の表示・非表示を isVisible にする |
| （常に） | プロジェクトの最終更新日時を更新する |

出力

| 状態 | 条件 | 本文 |
|---|---|---|
| 204 | （常に） | なし |

エラー

| 状態 | 条件 |
|---|---|
| 400 | 本文が入力の形に合わない |
| 404 | fieldId の項目がプロジェクトに無い |
| 409 | プロジェクトに取り込み待ち・取り込み中のインポートがある |

### DELETE /api/projects/{projectId}/fields/{fieldId}（項目の削除）

入力

| 場所 | 名前 | 型 | 必須 | 内容 |
|---|---|---|---|---|
| パス | projectId | 整数 | 必須 | プロジェクトの ID |
| パス | fieldId | 整数 | 必須 | 項目の ID |

処理

| 条件 | 処理 |
|---|---|
| （常に） | 項目を、各カードのその項目の値とともに削除する |
| （常に） | プロジェクトの最終更新日時を更新する |

出力

| 状態 | 条件 | 本文 |
|---|---|---|
| 204 | （常に） | なし |

エラー

| 状態 | 条件 |
|---|---|
| 404 | fieldId の項目がプロジェクトに無い |
| 409 | プロジェクトに取り込み待ち・取り込み中のインポートがある |
