## 外部仕様（What）

### GET /api/projects/{projectId}/cards（カードの一覧）

入力

| 場所 | 名前 | 型 | 必須 | 内容 |
|---|---|---|---|---|
| パス | projectId | 整数 | 必須 | プロジェクトの ID |
| クエリ | q | 文字列 | 任意 | 値で絞り込む文字列 |
| クエリ | sort | id・order・項目の ID | 任意 | 並べる基準（既定は id） |
| クエリ | direction | asc・desc | 任意 | 並べる向き（既定は asc） |

処理

| 条件 | 処理 |
|---|---|
| （常に） | プロジェクトのカードを取得する |
| q がある | 値に q を含むカードだけにする |
| sort が無いか id | ID の順に並べる |
| sort が order | 並び順の順に並べ、並び順が同じなら ID の順にする |
| sort が項目の ID | その項目の値の順に並べ、値が同じなら ID の順にする |
| direction が無いか asc | 昇順に並べる |
| direction が desc | 降順に並べる |

出力

| 状態 | 条件 | 本文 |
|---|---|---|
| 200 | （常に） | カードの配列（items）と、プロジェクトのカードの総数（total。q で絞り込む前の数）。各カードに、値（contents）・画像（images。追加した順）・複製元のカード（original）・複製先のカード（duplicates。複製先のプロジェクトの名前つき）を付ける |

エラー

| 状態 | 条件 |
|---|---|
| 400 | sort・direction が入力の形に合わない |
| 409 | プロジェクトに取り込み待ち・取り込み中のインポートがある |

### POST /api/projects/{projectId}/cards（カードの追加）

入力

| 場所 | 名前 | 型 | 必須 | 内容 |
|---|---|---|---|---|
| パス | projectId | 整数 | 必須 | プロジェクトの ID |
| 本文（JSON） | nextToId | 整数 | 任意 | このカードのすぐ下に追加する |
| 本文（multipart） | image | 画像のファイル | 任意 | 追加するカードに付ける画像 |

処理

| 条件 | 処理 |
|---|---|
| （常に） | カードの ID を、プロジェクトの中でいちばん大きい ID の次にする |
| nextToId が無い | 並び順の末尾に追加する |
| nextToId がある | そのカードのすぐ下に追加し、プロジェクトのカードの並び順を 1 から振り直す |
| image がある | 画像を保存し、カードに付ける |
| （常に） | プロジェクトの最終更新日時を更新する |

出力

| 状態 | 条件 | 本文 |
|---|---|---|
| 200 | nextToId が無い | 追加したカード。画像（images）を付ける |
| 204 | nextToId がある | なし |

エラー

| 状態 | 条件 |
|---|---|
| 400 | 本文が入力の形に合わない |
| 400 | nextToId のカードがプロジェクトに無い |
| 400 | image が画像のファイルでない |
| 409 | プロジェクトに取り込み待ち・取り込み中のインポートがある |

### PUT /api/projects/{projectId}/cards（カードの並び替え）

入力

| 場所 | 名前 | 型 | 必須 | 内容 |
|---|---|---|---|---|
| パス | projectId | 整数 | 必須 | プロジェクトの ID |
| 本文（JSON） | （配列） | id・order の組の配列 | 必須 | プロジェクトの全カードの ID と並び順 |

処理

| 条件 | 処理 |
|---|---|
| （常に） | 各カードの並び順を送った値にする |
| （常に） | プロジェクトの最終更新日時を更新する |

出力

| 状態 | 条件 | 本文 |
|---|---|---|
| 204 | （常に） | なし |

エラー

| 状態 | 条件 |
|---|---|
| 400 | 本文が入力の形に合わない |
| 400 | 送ったカードの数がプロジェクトのカードの数と違う |
| 409 | プロジェクトに取り込み待ち・取り込み中のインポートがある |

エラー

| 状態 | 条件 |
|---|---|

| 409 | プロジェクトに取り込み待ち・取り込み中のインポートがある |

### POST /api/projects/{projectId}/cards/duplicate（カードの複製）

入力

| 場所 | 名前 | 型 | 必須 | 内容 |
|---|---|---|---|---|
| パス | projectId | 整数 | 必須 | プロジェクトの ID |
| 本文（JSON） | cardId | 整数の配列 | 必須 | 複製するカードの ID（1 つ以上） |
| 本文（JSON） | toProjectId | 整数 | 任意 | 複製先のプロジェクトの ID |
| 本文（JSON） | nextToId | 整数 | 任意 | このカード（複製するカードのどれか）のすぐ下に複製する |

処理

| 条件 | 処理 |
|---|---|
| （常に） | カードを、値・画像（ファイルも）とともに複製する |
| （常に） | 複製したカードに、複製元のカードを覚えさせる |
| （常に） | 複製先に無い名前の項目を、複製先の項目の末尾に作る |
| toProjectId がある | そのプロジェクトの末尾に、元の並び順で複製する |
| toProjectId が無い | 「無題のプロジェクト」を作り、そこに複製する |
| nextToId がある | そのカードのすぐ下に複製し、複製先のカードの並び順を 1 から振り直す |
| （常に） | 複製先のプロジェクトの最終更新日時を更新する |

出力

| 状態 | 条件 | 本文 |
|---|---|---|
| 200 | （常に） | 複製したカードの配列 |

エラー

| 状態 | 条件 |
|---|---|
| 400 | 本文が入力の形に合わない |
| 400 | toProjectId のプロジェクトが無い |
| 409 | プロジェクトに取り込み待ち・取り込み中のインポートがある |

## 補足情報

### 実装との乖離

- カードの追加（POST /api/projects/{projectId}/cards）: 画像を付けずに追加すると、プロジェクトの最終更新日時を更新しない（[ISSUES.md](../../ISSUES.md#カードを追加しても最終更新日時が変わらない)）
- カードの複製（POST /api/projects/{projectId}/cards/duplicate）: toProjectId を送らずに作ったプロジェクトには、オーナーを設定しない（[ISSUES.md](../../ISSUES.md#新しいプロジェクトに複製するとプロジェクトを開けない)）
