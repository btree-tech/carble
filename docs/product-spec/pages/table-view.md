# テーブルビュー（プロジェクト詳細・カード一覧）

パス: `/projects/:id`

## ユーザーストーリー（Why）

- 研究者が、カードを表の形で一覧し、セルに直接入力することで、表計算ソフトのように素早くデータを蓄積したい（推測）
  - 研究者が、入力しながら打ち込みにくさを感じずに入力したい（[CESCHI-161](https://kinako.atlassian.net/browse/CESCHI-161)）
  - 研究者が、ブラウザの幅いっぱいに表を広げることで、多くの項目を一度に見たい（[CESCHI-164](https://kinako.atlassian.net/browse/CESCHI-164)）
- 研究者が、項目で並び替えたりキーワードで絞り込んだりすることで、目的のカードを探したい（推測。ソート・フィルターの要望自体は [CESCHI-114](https://kinako.atlassian.net/browse/CESCHI-114)、[CESCHI-115](https://kinako.atlassian.net/browse/CESCHI-115) にあるが理由の記載なし）
- 研究者が、グリッドビューやインポートで決めた並び順でカードを見ることで、資料の順番どおりに作業したい（[CESCHI-179](https://kinako.atlassian.net/browse/CESCHI-179)）
- 研究者が、プロジェクトに合わせて項目を追加・編集・非表示・並び替えすることで、扱う資料に合った表にしたい（推測）
- 研究者が、削除の前に確認されることで、誤ってデータを消さないようにしたい（[CESCHI-110](https://kinako.atlassian.net/browse/CESCHI-110)）

## 外部仕様（What）

### ヘッダー

- 「ホーム」リンク、プロジェクト名の入力欄、「スキャン」ボタンを表示する
  - **WHEN** 「ホーム」を押すと、[プロジェクト一覧](project-list.md)に遷移する
  - **WHEN** プロジェクト名を変更すると、入力が止まってから 1 秒後に保存する
  - 「スキャン」は [スキャン](../features/scan.md) を参照
- 「グリッドビュー」「カード印刷ビュー」「プロジェクト設定」ボタンと、検索の入力欄、保存状態のアイコンを表示する
  - **WHEN** 「グリッドビュー」を押すと、[グリッドビュー](grid-view.md)に遷移する
  - **WHEN** 「カード印刷ビュー」を押すと、すべてのカードの[カード印刷ビュー](print-view.md)に遷移する
  - **WHEN** 「プロジェクト設定」を押すと、[プロジェクト設定](project-settings.md)に遷移する
  - 保存状態のアイコンは [画面共通](../features/common-layout.md#保存状態のアイコン) を参照
- **WHERE** スマホ幅の場合、「ホーム」「グリッドビュー」「カード印刷ビュー」「プロジェクト設定」と、一覧の「カード入力」「追加」の文言を省いてアイコンだけにする
- **WHERE** オーナーの場合、まだ知らせていないインポートのうち、最も新しい 1 件の結果を表示し、知らせたことにする
  - **WHERE** インポートが完了した場合、「インポートが完了しました」と表示する
  - **WHERE** インポートが失敗した場合、「インポートに失敗しました」と表示する
  - どちらも「詳細」ボタンで[プロジェクト設定のインポート](project-settings.md#インポート)に遷移する
- **WHILE** インポート中は、カードの一覧の代わりに「インポート中です」のダイアログを表示する（[インポート・エクスポート](../features/import-export.md#インポート中の画面)）

### カードの一覧

- 列は左から、並び順、「カード入力」ボタン、選択のチェックボックス、ID、項目（項目の並び順）、カードのメニュー「…」とする
  - **WHERE** 項目を非表示にしている場合、その項目の列を表示しない
- カードを並び順の昇順に表示する
  - 並び順は、[グリッドビュー](grid-view.md)での並び替え、「直下に追加」「直下に複製」、[インポート](../features/import-export.md#インポート)の行の順で決まる
- **WHEN** 「カード入力」を押すと、そのカードの[カード入力ビュー](card-view.md)に遷移する。今の並び替えと検索の条件を引き継ぐ
  - **WHERE** カードに画像がある場合、「カード入力」のアイコンを画像のアイコンにする
- カードの件数を「全 N 件」と表示する
  - **WHILE** 検索中は、「（表示件数） / （全件数） 件表示中」と表示する
  - **WHERE** スマホ幅の場合、件数を表示しない
- 選択のチェックボックスは [カードの選択と一括操作](../features/card-selection.md) を参照

### 並び替え

- 列の見出し（並び順・ID・項目名）を押すと、その列で並び替える
  - **WHEN** 並び替えていない列の見出しを押すと、昇順に並び替える
  - **WHEN** 昇順に並び替えている列の見出しを押すと、降順に並び替える
  - **WHEN** 降順に並び替えている列の見出しを押すと、昇順に並び替える
  - 項目の値は文字列として比べる
  - 今の検索の条件を引き継ぐ
- 並び替えている列の見出しに、向き（昇順・降順）を示す矢印を表示する。ほかの列の見出しには上下の矢印を表示する

### 検索

- **WHEN** 検索の入力欄に文字を入れて Enter を押すと、いずれかの項目の値にその文字を含むカードだけを表示する
  - 非表示の項目の値も検索の対象とする。ID は検索の対象としない
  - 半角英字の大文字と小文字は区別しない
  - 今の並び替えの条件を引き継ぐ
- **WHEN** 検索の入力欄の「×」を押すと、検索をやめてすべてのカードを表示する

### カードの値の入力

- **WHEN** セルを押すと、そのセルの値を複数行で編集できる入力欄を開く
  - **WHEN** 値を変更すると、入力が止まってから 1 秒後に保存する
  - **WHEN** 入力欄の外を押すと、保存して入力欄を閉じる

### 項目の編集

- 見出しの右端の「…」を押すと、「項目を編集」と「新しい項目を追加」を開く
- 「項目を編集」には、非表示の項目も含めて、項目ごとに、並び替えのつまみ、項目名の入力欄、表示／非表示の切り替え、削除のボタンを表示する
  - **WHEN** つまみをドラッグして項目を並び替えると、その順を保存し、表の列の順に反映する
  - **WHEN** 項目名を変更すると、入力が止まってから 1 秒後に保存する
  - **WHEN** 表示／非表示を切り替えると、保存し、表とカード入力ビューでその項目を表示する／しない
  - **WHEN** 削除を押すと、「削除してよろしいですか？」と確認する
    - **WHEN** 確認すると、項目と、すべてのカードのその項目の値を削除する
- 「新しい項目を追加」には、項目名の入力欄（「項目名」）と「追加」ボタンを表示する
  - **WHILE** 項目名が空の間は、「追加」を押せない
  - **WHEN** 「追加」を押すと、項目を末尾に追加し、入力欄を空にする

### カードの追加

- 一覧の下に「追加」ボタンを表示する
- **WHEN** 「追加」を押すと、空のカードを末尾に追加し、「追加しました」と表示する
  - 新しいカードの ID は、プロジェクトのカードの ID の最大値に 1 を足した値とする

### カードのメニュー

- 各行の「…」を押すと、次のメニューを開く

| メニュー | 動作 |
|---|---|
| 直下に追加 | 選んだカードのすぐ下に空のカードを追加し、「追加しました」と表示する |
| 直下に複製 | 選んだカードを複製してすぐ下に置き、「複製しました」と表示する |
| 末尾に複製 | 選んだカードを複製して末尾に置き、「複製しました」と表示する |
| 別プロジェクトに複製 | 複製先のプロジェクトを選ぶダイアログ（「別プロジェクトに複製」）を開く（[カードの複製](../features/card-duplicate.md#別のプロジェクトへの複製)）。複製すると「複製しました」と表示し、複製先のテーブルビューに遷移する |
| 複製元カードを表示 | 複製元のカードの[カード入力ビュー](card-view.md)に遷移する。複製元が無いカードでは選べない |
| 複製先カードを表示 | 複製先のカードを選ぶダイアログ（「複製先カード」）を開く（[カードの複製](../features/card-duplicate.md#複製元と複製先)）。複製先が無いカードでは選べない |
| 削除 | 「削除してよろしいですか？」と確認し、確認するとカードを削除して「削除しました」と表示する |

- 「直下に追加」「直下に複製」では、カードの並び順を 1 から振り直す

## 補足情報

### 実装との乖離

- 項目名の見出しを押しても、その項目では並び替わらない。並び順の昇順で表示し（降順で並び替えていた場合も昇順に戻る）、矢印も並び順の列に出る（ID・並び順の見出しは仕様どおり並び替わる）（[ISSUES.md](../../ISSUES.md#項目名で並び替えられない)）
- 検索の文字に「&」「#」「+」を含むと、入れた文字のとおりに検索されない（「&」から後ろが落ち、「+」は空白になる。「#」を含むと一覧が空になる）。また「%」「_」は任意の文字に当たる（[ISSUES.md](../../ISSUES.md#検索の文字に記号を含むと入れたとおりに検索されない)）
- カードを削除して並び順の数字が飛んでいると、「直下に追加」「直下に複製」をしたカードがすぐ下に入らず、並び順がほかのカードと重なる（[ISSUES.md](../../ISSUES.md#並び順が飛んでいると直下に追加直下に複製がすぐ下に入らない)）
