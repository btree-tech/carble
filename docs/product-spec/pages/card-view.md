# カード入力ビュー

パス: `/projects/:id/cards/:cardId`

## ユーザーストーリー（Why）

- 研究者が、1 枚のカードの項目と画像をまとめて見ながら入力することで、資料 1 点ずつ丁寧に記録したい（推測、確信度: 中）
- 研究者が、前後のカードへ移ったり、最後のカードからそのまま次のカードを追加したりすることで、手を止めずに入力を続けたい（CESCHI-127、CESCHI-162）
- 研究者が、資料の写真をカードに添えることで、元の資料と記録を一緒に残したい（推測、確信度: 高）
- 研究者が、カード入力ビューからそのカードだけを印刷することで、1 枚ずつ確認や配布をしたい（CESCHI-126）

## 外部仕様（What）

### ヘッダー

- プロジェクト名と「スキャン」ボタンを表示する（[スキャン](../features/scan.md)）
- 「テーブルビュー」「カード印刷ビュー」ボタン、保存状態のアイコン、カードのメニュー「…」を表示する
  - **WHEN** 「テーブルビュー」を押すと、[テーブルビュー](table-view.md)に遷移する。並び替えと検索の条件を引き継ぐ
  - **WHEN** 「カード印刷ビュー」を押すと、このカードだけの[カード印刷ビュー](print-view.md)に遷移する。並び替えと検索の条件を引き継ぐ
  - 保存状態のアイコンは、項目の値の保存の状態を表す（[画面共通](../features/common-layout.md#保存状態のアイコン)）

### カードの内容

- 項目と画像を左右に並べて表示する
  - **WHERE** 画面が縦長の場合、画像を項目の下に表示する
- 「ID」「並び順」として、カードの ID と並び順を表示する
- 表示している項目ごとに、項目名と値の入力欄を表示する
  - **WHERE** 項目を非表示にしている場合、その項目を表示しない
  - **WHEN** 値を変更すると、入力が止まってから 1 秒後に保存する
- 項目の下に「＋」ボタンを表示する
- **WHEN** 「＋」を押すと、「新しい項目を追加」の入力欄（プレースホルダー「項目名」）を開く
  - **WHEN** 項目名を入れて「追加」を押すと、項目を末尾に追加して閉じる
  - **WHILE** 項目名が空の間は、「追加」を押せない

### 画像

- カードの画像を、追加した順に縮小して表示する
- **WHEN** 画像にマウスを乗せると、「元の画像を表示」「画像を削除」ボタンを表示する
  - **WHEN** 「元の画像を表示」を押すと、元の大きさの画像を別のタブで開く
  - **WHEN** 「画像を削除」を押すと、確認せずに画像を削除する
- 「画像を追加」ボタンを表示する
  - **WHEN** 「画像を追加」を押すと、画像を選ぶ画面を開く
    - **WHERE** スマホ・タブレットの場合、カメラを起動して撮影できる
    - **WHEN** 画像を選ぶと、カードの末尾に画像を追加する
    - **IF** 画像以外のファイルを選んだ場合、追加しない

### 前後のカード

- 前後のカードは、テーブルビューで並び替え・検索した順で決める
- **WHERE** 前のカードがある場合、「前」ボタンを表示する
  - **WHEN** 「前」を押すと、前のカードのカード入力ビューに遷移する
- **WHERE** 次のカードがある場合、「次」ボタンを表示する
  - **WHEN** 「次」を押すと、次のカードのカード入力ビューに遷移する
- **WHERE** 次のカードが無い場合、「次」の代わりに「追加」ボタンを表示する
  - **WHEN** 「追加」を押すと、空のカードを末尾に追加して「追加しました」と表示し、追加したカードのカード入力ビューに遷移する

### カードのメニュー

- 「…」を押すと、次のメニューを開く

| メニュー | 動作 |
|---|---|
| 直下に複製 | このカードを複製してすぐ下に置き、「複製しました」と表示し、複製したカードのカード入力ビューに遷移する |
| 末尾に複製 | このカードを複製して末尾に置き、「複製しました」と表示し、複製したカードのカード入力ビューに遷移する |
| 別プロジェクトに複製 | 複製先のプロジェクトを選ぶダイアログを開く（[カードの複製](../features/card-duplicate.md#別のプロジェクトへの複製)）。複製した後は[カードの複製](../features/card-duplicate.md#複製した後の画面)のとおり遷移する |
| 複製元カードを表示 | 複製元のカードのカード入力ビューに遷移する。複製元が無いカードでは選べない |
| 複製先カードを表示 | 複製先のカードを選ぶダイアログを開く（[カードの複製](../features/card-duplicate.md#複製元と複製先)）。複製先が無いカードでは選べない |
| 削除 | 「削除してよろしいですか？」と確認し、確認するとカードを削除して「削除しました」と表示する。次のカードがあれば次のカードのカード入力ビューに、無ければテーブルビューに遷移する |

## 補足情報

### 実装との乖離

- 「削除」の確認で取り消しても、カードは削除しないが、次のカード（無ければテーブルビュー）に遷移する（[ISSUES.md](../../ISSUES.md#カード入力ビューでカードを削除すると次のカードに遷移しない)）
- 「削除」の確認後にカードを削除しても、次のカードに遷移しない。次のカードがあっても、テーブルビューに遷移する（[ISSUES.md](../../ISSUES.md#カード入力ビューでカードを削除すると次のカードに遷移しない)）
- 検索の条件を引き継いでいるときに「追加」を押すと、追加した空のカードは検索に当たらないため、遷移した先に検索結果の最後のカードを表示する。そのまま入力した値や追加した画像は、表示しているカード（検索結果の最後のカード）に保存する（[ISSUES.md](../../ISSUES.md#検索中にカードを追加すると別のカードを表示する)）
- 「別プロジェクトに複製」で「新しいプロジェクト」に複製すると、作ったプロジェクトにオーナーが設定されず、遷移した先は空の画面になる（エラー画面は表示しない）（[ISSUES.md](../../ISSUES.md#新しいプロジェクトに複製するとプロジェクトを開けない)）
