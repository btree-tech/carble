# グリッドビュー

パス: `/projects/:id/grid`

## ユーザーストーリー（Why）

- 研究者が、カードを画像付きのタイルで並べ、ドラッグで並び替えることで、カード群を再編したい（CESCHI-173）
  - 研究者が、並び替えたカードを選んで別のプロジェクトに複製することで、再編したカード群から新しいプロジェクトを作りたい（CESCHI-174）

## 外部仕様（What）

### ヘッダー

- プロジェクト名、「テーブルビュー」ボタン、保存状態のアイコンを表示する
  - **WHEN** 「テーブルビュー」を押すと、[テーブルビュー](table-view.md)に遷移する
  - **WHERE** スマホ幅の場合、「テーブルビュー」ボタンの文言を省いてアイコンだけにする
  - 保存状態のアイコンは、並び替えの保存の状態を表す（[画面共通](../features/common-layout.md#保存状態のアイコン)）

### カードの表示

- カードを並び順の昇順に、タイルで並べて表示する
- 各タイルに「表示項目1」「表示項目2」で選んだ内容と、「カード入力」ボタンを表示する
  - **WHERE** 選んだ内容が画像の場合、カードの 1 枚目の画像を表示する
  - **WHERE** 選んだ内容が ID の場合、「ID: （ID）」と表示する
  - **WHERE** 選んだ内容が項目の場合、その項目の値を表示する
- 「表示項目1」「表示項目2」の選択欄を表示する
  - 選べるのは「画像」「ID」と、すべての項目（非表示の項目も含む）とする
  - 初期値は「表示項目1」が画像、「表示項目2」が ID とする
  - 選んだ内容は、同じプロジェクトの画面を移っても保持する。保存はせず、ブラウザを再読み込みすると初期値に戻る
- **WHEN** 「カード入力」を押すと、そのカードの[カード入力ビュー](card-view.md)に遷移する

### 並び替え

- **WHEN** タイルをドラッグして別の位置に置くと、表示どおりの順に並び順を 1 から振り直して保存する

### 選択

- **WHEN** 各タイルにマウスを乗せると、選択のチェックボックスを表示する
  - **WHILE** 1 件以上選んでいる間は、すべてのタイルにチェックボックスを表示し、選んだタイルに色を付ける
- **WHEN** タイルの「カード入力」以外の場所を押すと、そのタイルの選択を切り替える
- **WHILE** Shift キーを押している間は、前に選んだタイルとの間のタイルをまとめて選ぶ（選択を外したときは、まとめて外す）
- 選んだカードの一括操作は [カードの選択と一括操作](../features/card-selection.md) を参照
