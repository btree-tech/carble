# プロジェクト一覧（トップ）

パス: `/`

## ユーザーストーリー（Why）

- 研究者が、自分が閲覧できるプロジェクトだけを一覧することで、目的のプロジェクトにすぐ移りたい（[CESCHI-204](https://kinako.atlassian.net/browse/CESCHI-204)）
  - 研究者が、各プロジェクトのオーナー名を見ることで、自分のプロジェクトと招待されたプロジェクトを見分けたい（[CESCHI-227](https://kinako.atlassian.net/browse/CESCHI-227)）
- 招待されたユーザーが、プロジェクト一覧で招待に気づき、承認または拒否したい（[CESCHI-212](https://kinako.atlassian.net/browse/CESCHI-212)）
- 研究者が、手元の表計算のファイルからプロジェクトを作ることで、既存のデータをそのまま Carble に移したい（[CESCHI-191](https://kinako.atlassian.net/browse/CESCHI-191)）
  - 研究者が、初期の項目（みだし・メモ）を作らずにインポートすることで、不要な項目を増やさないようにしたい（[CESCHI-191](https://kinako.atlassian.net/browse/CESCHI-191)）

## 外部仕様（What）

### ヘッダー

- ロゴと、ログインしているユーザーの名前のボタンを表示する
- **WHEN** 名前のボタンを押すと、「設定」「ログアウト」のメニューを開く
  - **WHEN** 「設定」を選ぶと、[設定（ユーザー）](user-settings.md)に遷移する
  - **WHEN** 「ログアウト」を選ぶと、ログアウトして[ログイン画面](login.md)に遷移する

### 招待の通知

- **WHERE** 招待されているプロジェクトがある場合、プロジェクトごとに「「（プロジェクト名）」に招待されています」と、「承認」「拒否」ボタンを表示する
  - 最終更新日時の新しいプロジェクトから順に並べる
  - **WHEN** 「承認」を押すと、そのプロジェクトのメンバー（編集者）になり、通知を消してプロジェクトの一覧に加える
  - **WHEN** 「拒否」を押すと、招待を取り消し、通知を消す

### プロジェクトの一覧

- メンバーになっているプロジェクトを、最終更新日時の新しい順に表示する
  - 招待中のプロジェクトは表示しない
- 「プロジェクト名」「オーナー」「最終更新日時」の列と、見出しの無い「詳細」ボタンの列を表示する
  - 「オーナー」の列には、オーナーの名前を表示する
  - 最終更新日時は、プロジェクトの作成、プロジェクト名・項目・カード・カードの内容・画像・並び順の変更、インポートの完了のうち、最も新しい日時とする
  - **WHERE** スマホ幅の場合、最終更新日時を表示せず、「詳細」ボタンは文言を省いてアイコンだけにする
- **WHERE** メンバーになっているプロジェクトが無い場合、一覧に「No items.」と表示する
- **WHEN** 「詳細」を押すと、そのプロジェクトの[テーブルビュー](table-view.md)に遷移する

### 新規プロジェクト

- 「新規プロジェクト」ボタンを表示する
  - **WHERE** スマホ幅の場合、文言を省いてメニューを開く矢印のアイコンだけにする
- **WHEN** 「新規プロジェクト」を押すと、「空白のプロジェクト」「ファイルをインポート」のメニューを開く
- **WHEN** 「空白のプロジェクト」を選ぶと、「無題のプロジェクト」という名前のプロジェクトを作成し、そのプロジェクトの[テーブルビュー](table-view.md)に遷移する
  - 作成したユーザーがオーナーになる
  - 項目「みだし」「メモ」を作成する。カードは 0 件とする
- **WHEN** 「ファイルをインポート」を選ぶと、「インポート」のダイアログを開く
  - ダイアログには、「ファイルを選択」ボタン・案内と「インポート」ボタンを表示する（[インポート](../features/import-export.md#インポート)と同じ）。「同じIDのカードを上書きする」は表示しない
  - **WHEN** ファイルを選んで「インポート」を押すと、ファイル名（拡張子を含む）をプロジェクト名にしてプロジェクトを作成し、インポートを始め、そのプロジェクトの[テーブルビュー](table-view.md)に遷移する
    - 作成したユーザーがオーナーになる
    - 項目は作成しない（インポートしたファイルの列から作る）

## 補足情報

### 実装との乖離

- オーナーがユーザーデータを削除したプロジェクトの編集者は、オーナー名を表示できず、この画面がエラー画面（500）になる（[ISSUES.md](../../ISSUES.md#ユーザーを削除してもオーナーのプロジェクトが残る)）
- 「追加」「直下に追加」でカードを追加しても、最終更新日時は新しくならない（スキャンで画像を添えて追加した場合は新しくなる）（[ISSUES.md](../../ISSUES.md#カードを追加しても最終更新日時が変わらない)）
