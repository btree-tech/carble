# 設定（ユーザー）

パス: `/users/edit`

## ユーザーストーリー（Why）

- 研究者が、登録したユーザーIDと名前を後から変更することで、共同作業の相手に分かりやすい表示にしたい（推測。プロフィール編集の要望自体は [CESCHI-204](https://kinako.atlassian.net/browse/CESCHI-204) にあるが理由の記載なし）
- 研究者が、使わなくなったユーザーデータを自分で削除することで、個人の情報を残さないようにしたい（推測）

## 外部仕様（What）

### ユーザーIDと名前の変更

- [ユーザー登録](user-register.md)と同じ入力欄・確認・「保存」ボタンを表示する
  - 自分の今のユーザーID は「既に使われています」としない
- ほかの画面へのリンク（プロジェクト一覧へ戻るリンクなど）は表示しない。保存するか、ブラウザの「戻る」で離れる
- **WHEN** 「保存」を押すと、ユーザーIDと名前を保存し、[プロジェクト一覧](project-list.md)に遷移する

### ユーザーデータの削除

- 入力欄の下に、区切り線をはさんで「ユーザーデータを削除」ボタンを表示する
- **WHEN** 「ユーザーデータを削除」を押すと、「本当に削除しますか？」と確認する
  - **WHEN** 確認すると、ユーザーを削除してログアウトし、[ログイン画面](login.md)に遷移する
    - 参加していたプロジェクトのメンバーからも外れる。受けていた招待も消える
  - **WHEN** 確認をキャンセルすると、何もしない

## 補足情報

### 実装との乖離

- 自分がオーナーのプロジェクトは、ユーザーを削除しても消えずに残る（[ISSUES.md](../../ISSUES.md#ユーザーを削除してもオーナーのプロジェクトが残る)）
  - 編集者がいない場合、誰も開けない
  - 編集者がいる場合、編集者のプロジェクト一覧はそのプロジェクトのオーナー名を表示できず、一覧の画面がエラー画面（500）になる
- 自分の今のユーザーID の大文字・小文字だけを変えると（「carble」を「Carble」にするなど）、「既に使われています」と表示し、保存できない（[ISSUES.md](../../ISSUES.md#自分のユーザーidの大文字小文字だけを変えると既に使われていますと表示する)）

### 関連機能

- [プロジェクト一覧](project-list.md): ユーザーメニューの「設定」からこの画面を開く
- [ユーザー登録](user-register.md)
