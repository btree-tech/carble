# プロジェクト設定

パス: `/projects/:id/settings`（全般）、`/projects/:id/settings/import`（インポート）、`/projects/:id/settings/users`（ユーザー管理）、`/projects/:id/settings/delete`（プロジェクト削除）

## ユーザーストーリー（Why）

- メンバーが、プロジェクトのデータをファイルに書き出すことで、手元にバックアップを残したり、表計算ソフトで扱ったりしたい（推測）
- オーナーが、表計算のファイルからカードを取り込むことで、既存のデータをまとめて登録・更新したい（推測）
  - オーナーが、上書きを明示的に選び、その前にバックアップを促されることで、意図せずカードの内容を失わないようにしたい（[CESCHI-227](https://kinako.atlassian.net/browse/CESCHI-227)、[CESCHI-232](https://kinako.atlassian.net/browse/CESCHI-232)）
- オーナーが、ユーザーIDを入力して他のユーザーを招待することで、共同で編集したい（[CESCHI-212](https://kinako.atlassian.net/browse/CESCHI-212)）
  - オーナーが、招待の前にバックアップを促されることで、共同編集を始める前の状態を残したい（[CESCHI-227](https://kinako.atlassian.net/browse/CESCHI-227)）
- オーナーが、設定の画面を左寄せで見ることで、読みやすくしたい（推測。左詰めの要望自体は [CESCHI-235](https://kinako.atlassian.net/browse/CESCHI-235) にあるが理由の記載なし）

## 外部仕様（What）

### ヘッダー

- プロジェクト名、「テーブルビュー」ボタン、タブを表示する
  - **WHEN** 「テーブルビュー」を押すと、[テーブルビュー](table-view.md)に遷移する
  - **WHERE** スマホ幅の場合、「テーブルビュー」の文言を省いてアイコンだけにする
- タブは「全般」とする
  - **WHERE** オーナーの場合、「インポート」「ユーザー管理」「プロジェクト削除」のタブも表示する（[ロールと権限](../features/roles.md)）

### 全般

- 「エクスポート」ボタンを表示する
- **WHEN** 「エクスポート」を押すと、プロジェクトのデータを zip ファイルでダウンロードする（[エクスポート](../features/import-export.md#エクスポート)）

### インポート

- ファイルの選択、「同じIDのカードを上書きする」チェック、「インポート」ボタンを表示する
  - 「xlsx,csv,zipファイルのいずれか（600MBまで）を選択してください」「zipファイルを選択し、かつ画像ファイル列が存在する場合、列で指定された画像ファイルを取り込みます」と案内を表示する
  - **WHEN** 「ファイルを選択」を押すと、xlsx・csv・zip のファイルを選ぶ画面を開く。選ぶとファイル名を表示する
  - **WHILE** ファイルを選んでいない間は、「インポート」を押せない
- **WHEN** 「同じIDのカードを上書きする」をチェックすると、次のメッセージと「OK」ボタンのダイアログを表示する
  - 「ID列に入力された数値と同IDのカードが存在する場合、そのカードの内容を上書きします。」
  - 「これからデータの更新を行います。現状のプロジェクトの状態を残しておきたい場合はバックアップを残しておくこと（プロジェクトデータの「エクスポート」）をお勧めします。」
  - **WHEN** 「OK」を押すと、ダイアログを閉じる
- **WHEN** 「インポート」を押すと、ファイルをアップロードしてインポートを始め、[テーブルビュー](table-view.md)に遷移する
  - 取り込みの内容は [インポート](../features/import-export.md#インポート) を参照
  - **WHILE** 「同じIDのカードを上書きする」をチェックしている間は、ID 列のカードを上書きする。チェックしていない間は、すべての行を新しいカードとして追加する
  - **IF** アップロードに失敗した場合、メッセージを表示せず、画面に留まる（[実装との乖離](#実装との乖離)）
- 「インポート履歴」に、このプロジェクトのインポートを新しい順に 10 件ずつ表示する
  - 列は「インポート日時」「ファイル名」「結果」とする
    - 「インポート日時」は、ファイルをアップロードした日時とする
  - **WHERE** スマホ幅の場合、「結果」を表示しない
  - 履歴の下に、ページを切り替えるボタンを表示する。10 件以下の場合も、1 ページだけのボタンを表示する
  - **WHERE** インポートの履歴が無い場合、「No items.」と表示する
  - 結果は次のとおり表示する

| 状態 | 結果の表示 |
|---|---|
| インポートを待っている | 未処理 |
| 取り込んでいる | インポート中 |
| 取り込みが終わった | インポート済（緑） |
| ファイルの形式・内容に誤りがあった | フォーマットエラー（赤） |
| 取り込みの途中で予期しないエラーが起きた | システムエラー（赤） |

  - **WHERE** 結果がフォーマットエラー・システムエラーの場合、行を開いてエラーの内容を表示できる

### ユーザー管理

- プロジェクトのユーザーを、プロジェクトに加えた順に一覧する
  - 列は「ユーザーID」「権限」「ステータス」と削除ボタンとする
  - オーナーの「権限」は「管理者」と表示する。編集者・招待中のユーザーは空欄とする
  - 招待中のユーザーの「ステータス」に「招待中」と表示する
  - **WHERE** オーナー以外の行の場合、「削除」ボタンを表示する
    - **WHERE** スマホ幅の場合、「削除」の文言を省いてアイコンだけにする
- **WHEN** 「削除」を押すと、「削除してよろしいですか？」と確認する
  - **WHEN** 確認すると、そのユーザーをプロジェクトから外し、一覧から消す
- 「ユーザーIDを入力して招待」の入力欄と「招待」ボタンを表示する
  - 「これから他のメンバーを招待して共同編集を行えるようにします。」「現状のプロジェクトの状態を残しておきたい場合はバックアップを残しておくこと（プロジェクトデータの「エクスポート」）をお勧めします。」と案内を表示する
  - **WHEN** ユーザーIDを入れて「招待」を押すと、そのユーザーを招待中として一覧に加え、入力欄を空にする
    - 招待されたユーザーの[プロジェクト一覧](project-list.md#招待の通知)に招待の通知を表示する
  - **IF** 存在しないユーザーIDの場合、「存在しないIDです」と表示し、招待しない
  - **IF** ユーザーIDが 3 文字未満または 30 文字を超える場合、メッセージを表示せず、招待しない

### プロジェクト削除

- 「プロジェクトを削除する」ボタンを表示する
- **WHEN** 「プロジェクトを削除する」を押すと、「削除してよろしいですか？」と確認する
  - **WHEN** 確認すると、プロジェクトと、そのカード・項目・画像（画像のファイルを含む）・インポート履歴、メンバー・招待中のユーザーとの関係を削除し、「プロジェクトを削除しました」と表示して[プロジェクト一覧](project-list.md)に遷移する

## 補足情報

### 実装との乖離

- 既にプロジェクトのメンバー（または招待中）のユーザーIDを招待しても、「存在しないIDです」と表示する（[ISSUES.md](../../ISSUES.md#招待済みのユーザーを招待すると存在しないidですと表示する)）
- 「エクスポート」を押すと、ダウンロードがサーバーのエラー（500）で失敗する（[ISSUES.md](../../ISSUES.md#エクスポートが失敗する)）
- スマホ幅では、インポート履歴の「結果」の見出しは表示しないが、各行の結果は表示する
- インポートのアップロードに失敗しても（ブラウザが送るファイルの種類が xlsx・csv・zip のどれとも判定されない場合など）、メッセージを表示しない
- オーナー以外にはタブを表示しないが、URL を直接開くと「インポート」「ユーザー管理」「プロジェクト削除」の画面を表示する。招待は「存在しないIDです」と表示し、削除はメッセージを表示せずに失敗する。インポートはサーバー側のオーナー判定が効いておらず、取り込めてしまう（[security-review/report.md](../../plans/security-review/report.md) の指摘 7）
- インポート中に、設定の画面（`/projects/:id/settings` 以下）を再読み込みしたり URL を直接開いたりすると、「インポート中です」のダイアログではなくエラー画面（409）を表示する（[ISSUES.md](../../ISSUES.md#インポート中にプロジェクトの画面を直接開くとエラー画面になる)）
