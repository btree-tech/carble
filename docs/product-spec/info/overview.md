# サービス概要

仕様を読むための参考情報。仕様そのものは [pages/](../pages/) と [features/](../features/) を参照。

## 用語

| 用語 | 内部名 | 説明 |
|---|---|---|
| プロジェクト | project | 1 つの表（シート）に当たる。カードと項目を持つ |
| カード | card | 表の 1 行に当たる。ID・並び順・項目の値・画像を持つ |
| 項目 | field | 表の 1 列に当たる。表示／非表示と並び順を持つ |
| 値（コンテンツ値） | content | カードの、ある項目の値 |
| 画像 | image | カードに添えた画像。1 枚のカードに複数持てる |
| ID | card.id | プロジェクトの中でカードに振る番号。プロジェクトごとに 1 から振り、新しいカードにはプロジェクトでいちばん大きい ID の次を振る（いちばん大きい ID のカードを消すと、その ID をもう一度使う） |
| 並び順 | card.order | カードを並べる順。カードの追加・複製・インポートでは末尾（指定したカードの次に追加・複製した場合はその次）に置き、グリッドビューで並び替える |
| ユーザー | user | Google アカウントでログインした人。ユーザーIDと名前を持つ |
| ユーザーID | username | ユーザーが登録する、他のユーザーと重ならない ID。招待に使う |
| オーナー | role = owner | プロジェクトを作ったユーザー。画面上は「管理者」（[ロールと権限](../features/roles.md)） |
| 編集者 | — | オーナーの招待を承認したユーザー |
| メンバー | — | オーナーと編集者をまとめた呼び方 |
| 招待中 | status = invited | 招待され、まだ承認していない状態 |
| インポート | import | ファイルからカードを取り込むこと。後から順に処理する |
| 複製元・複製先 | original / duplicates | 複製したカードと、その元のカード |

## 利用フロー（基本シナリオ）

1. 研究者が Google アカウントでログインし、ユーザーIDと名前を登録する
2. 研究者がプロジェクトを作る（空白のプロジェクト、または手元のファイルをインポート）
3. 研究者がテーブルビューかカード入力ビューで、項目を整えながらカードを入力する。資料の写真を添える
4. 研究者がカード印刷ビューでカードを印刷する。印刷したカードと資料を一緒に撮影すると、スキャンで写真をそのカードに添えられる
5. 研究者がグリッドビューでカードを並び替え、必要なカードを別のプロジェクトに複製して再編する
6. オーナーがプロジェクト設定で他のユーザーを招待し、招待されたユーザーが承認すると、共同で編集できる
7. 研究者がエクスポートでデータと画像を書き出し、表計算ソフトで編集して、オーナーがインポートで戻す

データの構造は [データモデル](data-model.md) を参照。
