# CESCHI-164 テーブルビューをブラウザの幅に合わせて広げる

## 背景（なぜ）

- 研究者がブラウザのウィンドウを広げても、テーブルビューの作業領域は一定の幅から広がらず、横のスクロールバーが出ていた。ウィンドウを大きくしたら、作業領域も大きくなってほしいという要望だった
- カード入力ビューは、一定の幅のままでよいとされた
- 表を広げた後、ヘッダーとフッターが元の幅のまま残ってちぐはぐに見えるという意見が出た。そのまま広げるとボタンが左右に離れてしまうため、ボタンを左側に集める形にした

## 決めたこと

- テーブルビューの表を、ブラウザの幅に合わせて広げる
- 画面が広い場合、テーブルビューのヘッダーとフッターは一定の幅を上限にして左に寄せる。スマホや狭い画面では、これまでどおり画面の幅いっぱいに表示する
- ほかの画面のヘッダーの配置は、今回は変えない
