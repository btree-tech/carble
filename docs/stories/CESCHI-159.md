# CESCHI-159 Safari でもカードを用紙の半分ずつに印刷する

## 背景（なぜ）

- CESCHI-157 の続き。研究者がプロジェクトのカードをまとめて印刷すると、A4 用紙 1 枚に 2 枚のカードがちょうど収まらず、Safari ではページが進むにつれてカードの境目がずれていった
- Safari では印刷の縮小率を変えてもずれたため、改ページの指定が効いていないと見て、ほかのブラウザより回避策が無く利用に支障が大きいとして先に調べることにした
- 後で確かめ直すと、ページをまたいでずれる現象は起きなくなっていたが、カードが用紙の上に寄り、ちょうど 2 分割にはなっていなかった

## 決めたこと

- Safari でも、2 枚のカードが用紙の半分ずつに近づくよう、Safari だけ印刷時のカードの高さを調整する
- あわせて、Chrome でカードの右の枠線が細く見える点を整える
- iOS・iPadOS の Safari では、用紙のちょうど半分では分かれないまま残っている。致命的なレイアウトの崩れではないと判断し、未対応として課題を閉じた
