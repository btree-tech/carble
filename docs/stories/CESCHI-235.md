# CESCHI-235 プロジェクト設定の画面を左寄せにする

## 背景（なぜ）

- プロジェクト設定の画面が中央寄せになっていたが、ほかの画面は左寄せのため、違和感があると研究者から指摘があった
- ほかの中央寄せの画面（カード印刷ビュー・グリッドビュー）もそろえるかを確かめたところ、そちらは中央のままでよいとのことだった

## 決めたこと

- プロジェクト設定の画面を、テーブルビューと同じように左寄せにする
- カード印刷ビューとグリッドビューは、中央寄せのままとする
