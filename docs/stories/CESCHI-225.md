# CESCHI-225 カード印刷ビューで、別のカードに移っても設定を保つ

## 背景（なぜ）

- カード印刷ビューで、あるカードで表示内容を調整した後に別のカードに移ると、固定領域1 の設定だけが初期の状態に戻ってしまうと研究者から報告があった。レイアウト全体・固定領域2・表示／非表示の設定は残っていた

## 決めたこと

- 別のカードに移っても、固定領域1 の設定も、ほかの設定と同じように保つ
