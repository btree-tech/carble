# CESCHI-232 インポートで、同じ ID のカードを上書きするかを明示的に選ぶ

## 背景（なぜ）

- インポートで、ファイルの ID 列と同じ ID のカードが上書きされ、意図せずカードの内容を失うことがあった（CESCHI-227）
- 上書きが気軽にできてしまうと、データを失いやすい。そこで、上書きは利用者が意識して選んだときだけに限り、その前にバックアップを勧めることにした。この部分を CESCHI-227 から分けて対応した

## 決めたこと

- インポートの画面に「同じ ID のカードは上書きする」のチェックを設ける
  - チェックを入れないままインポートすると、ID 列の有無にかかわらず、カードを追加する
  - チェックを入れてインポートすると、ID 列と同じ ID のカードを上書きする
- チェックを入れたときに、同じ ID のカードを上書きすることと、エクスポートでバックアップを残すことを勧める案内を表示する
- チェックを選べるようにしたため、ファイルを選んだだけではインポートを始めず、ボタンを押して始める形に変えた
- ファイルから新しいプロジェクトを作るときは、上書きするカードが無いため、このチェックを表示しない
