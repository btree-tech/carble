# CESCHI-157 カードの印刷を用紙の半分ずつにそろえ、カードの間に余白を入れる

## 背景（なぜ）

- 研究者が、プロジェクトのカードをまとめて印刷すると、カードが続けて並び、A4 用紙 1 枚に 2 枚がちょうど収まる大きさになっていなかった。そのため、1 枚目と 2 枚目の境目が用紙の半分より上に寄っていた
- ブラウザによって崩れ方が違った。Firefox では境目が上に寄り、Safari ではページが進むにつれて境目がずれていった。Chrome では問題がなかった
- 研究者は、印刷した用紙を 2 枚のカードに切り離して使うつもりでいた。カードとカードの間に余白が無いと切り離しにくいため、数ミリの余白が欲しいという要望も合わせて出た
- 手直しが比較的容易な範囲で対応する、という前提で進めた

## 決めたこと

- Firefox で、2 枚のカードが用紙のちょうど半分ずつに分かれるようにする
- 切り離しやすいよう、カードとカードの間に余白を入れる
- Safari でページが進むとずれる問題は、続きの課題（CESCHI-159）で扱う
