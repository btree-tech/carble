# CESCHI-110 項目やカードを削除する前に確認する

## 背景（なぜ）

- 課題では、列（項目）やカードを削除する直前に確認を出すことを求めている。なぜ求めたのかは、課題に書かれていない
- 課題の元になった要望の一覧では、列やカードの削除が気軽に実行できてしまうことが問題として挙げられていた
- 同じ一覧には、削除したカードをいったんプロジェクトごとのゴミ箱に移し、後から戻せるようにする案（元に戻す機能）もあった。その機能があればカードの確認は要らなくなりそうだと見たうえで、まずは削除の前に確認を出す形で対応することにした

## 決めたこと

- 項目やカードを削除する操作の前に、削除してよいかを確認する。確認したときだけ削除する
