# CESCHI-173 グリッドビューでカードを並べ、並び替える

## 背景（なぜ）

- 研究者から「カード群を再編して、新しいプロジェクトを作りたい」という要望があった。この課題は、そのうちのカード群の再編を担う
- 要望の中身は、印刷したカードを並べ替えて新しいまとまりを作り、それをスキャンして新しいプロジェクトにまとめたい、というものだった。紙を経ずに、カードの順番を入れ替えたり一部を除いたりして新しいプロジェクトを作りたい、既存のプロジェクトにも好きな位置に加えたい、という希望もあった
- 要望の優先度を確かめた際、少なくともカードの ID と並び順を分けることが求められた
- 仕様の検討では、プロジェクトとは別に、カードを集めて並べ替えるための一時的な作業場所を設ける案も出た。しかし、利用者が新しい概念を覚える必要があり、共同編集での権限の扱いも複雑になる。そこで、作業場所を別に作らず、プロジェクトの表示の一つとしてグリッドビューを加える方針にした。再編したい場合は、別のプロジェクトにカードを複製してグリッドビューで並べればよい
- 並び順はプロジェクトを共同で整理するためのものなので、利用者ごとではなく、全員で共通にした
- タブレットでも使うため、マウスやキーボードに頼らない選び方が必要とされた

## 決めたこと

- プロジェクトのカードを、タイルにして並べるグリッドビューを設ける。タイルに表示する項目は、作業の内容に合わせて選べる
- ドラッグでカードを並び替え、その並び順をプロジェクトの全員で共通の並び順として保存する
- カードは、タイルを押すだけで選べるようにする（タッチ操作でも、Shift キーやマウスを乗せる操作に頼らずに選べる）
- グリッドビューは並び替えが主な目的なので、ドラッグ中に意図せず移動しないよう、カード入力ビューへは専用のリンクから移る
- テーブルビューからグリッドビューへ移れるようにする
