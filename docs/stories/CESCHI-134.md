# CESCHI-134 印刷ビューのレイアウトと画像の枚数を選ぶ

## 背景（なぜ）

- 印刷ビューで、情報を詰めて表示したいという要望があった。プロジェクトごとに体裁を決め、罫線も入れたいという希望もあった（CESCHI-128）
- あわせて、印刷する画像の枚数や大きさを指定したいという要望があった（CESCHI-128）
- 仕様を検討した結果、決まった形のレイアウトをいくつか用意し、その中から選ぶ方式にした
- 罫線は、領域からはみ出した部分を切ると見栄えが悪くなるため、いったん入れないことにし、要望があれば検討することにした

## 決めたこと

- 3 種類のレイアウトから 1 つを選ぶ。選ぶ欄はサムネイルではなくプルダウンとする
- レイアウトの決まった領域（固定領域）ごとに、画像・ID・どの項目を表示するかを選ぶ
- 残りの項目は、固定領域以外の領域（任意項目）に項目の順に表示する。固定領域で選んだ内容は任意項目から除く。任意項目には画像も表示できる
- 領域からはみ出す内容は切る
- 印刷する画像の枚数を選べるようにする。0 はすべての画像を表示する
- 任意項目の表示・非表示を切り替えられるようにし、初期値はテーブルビューでの表示・非表示に合わせる
- 固定領域に選んだ項目が削除された場合は、その領域を空欄のままにする
- 印刷したときに前後に白紙のページが出ないようにする
- 印刷ビューの設定の保存は、この課題では行わず、別の課題（CESCHI-152）に分けた
