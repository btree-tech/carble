# CESCHI-114 テーブルビューを項目で並び替える

## 背景（なぜ）

- 課題では、テーブルビューで項目ごとに並び替えられるようにすることを求めている。なぜ求めたのかは、課題に書かれていない
- 課題の元になった要望の一覧では、この並び替えは、カード入力ビューで前後のカードに移る機能（CESCHI-127）と関連づけられていた。並び替えた順番で、前後のカードを表示する想定だった
- 実装を確かめた際、入力している最中に並び替えが走ると行が動いてしまうことが分かり、並び替えはボタンを押したときだけにすることにした
- 並び替えの向きを示す矢印は、表計算ソフトと同じく、今の並び替えの状態を表す向きにそろえた

## 決めたこと

- 項目の見出しごとに並び替えのボタンを置き、押すたびに昇順・降順を切り替える
- 並び替えるのは、ボタンを押したときだけとする
- 並び替えの条件を URL に含め、ブックマークで同じ表示に戻れるようにする
- 並び替えの条件はプロジェクトに保存しない
- データが増えても表示が重くならないよう、並び替えは検索（CESCHI-115）とあわせてサーバー側で行う
