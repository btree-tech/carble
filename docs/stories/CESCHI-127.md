# CESCHI-127 カード入力ビューで次のカードに移る

## 背景（なぜ）

- 課題では、カード入力ビューから次のカードを表示できるようにし、その際にテーブルビューの並び替え（できれば絞り込みも）を考慮することを求めている。なぜ求めたのかは、課題に書かれていない

## 決めたこと

- カード入力ビューに、前後のカードへ移るボタンを置く。置き場所は画面の下とした
- 前後のカードは、テーブルビューで選んだ並び替えと絞り込みの条件に従って決める

## 反映した仕様

- [カード入力ビュー](../product-spec/pages/card-view.md)
