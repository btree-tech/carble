# CESCHI-85 研究データをためるツールの最初の年の開発

## 背景（なぜ）

- 人文系の研究者が、研究の途中で生まれるデータを、扱いやすい形でためられるツールの試作を目指した
- 研究者への聞き取りをもとに、ツールが満たすべき要件を 5 つにまとめた（決めたことを参照）

## 決めたこと

- 次の 5 つを満たすツールを作る
  - データを、CSV や JSON などに変換しやすい、整った表の形でためる
  - 知的生産の手法として定評のある、カード式の情報整理法を取り入れた画面にする
  - カード式の整理法でよく行う、紙のカードを並べたり書き込んだりする作業を、印刷した紙で行えるようにする
  - 紙の上で行った作業を、デジタルのデータと結び付けられるようにする
  - 複数の研究プロジェクトを扱えるようにする
- 最初の年の終わりに、プロジェクトの一覧、表の画面、カードの入力画面、紙とデータを結び付ける機能、印刷の画面、項目の並び替え・非表示を作った
