# CESCHI-156 インポートをバックグラウンドで実行する

## 背景（なぜ）

- 研究者が、他の人のデータを自分の作業しやすい形に直すため、エクスポートしたファイルを表計算ソフトで編集し、もう一度取り込もうとしたところ、取り込みの画面が読み込み中のまま止まり、画面から抜け出せなくなった。抜けた後も、作りかけのプロジェクトを削除できなかった
- 数千件のカードを取り込むと、サーバーの応答が返らずタイムアウトのエラーになることも分かった
- 研究者からは、1 つのプロジェクトで扱えるデータの量の上限を上げたい（印刷ビューも含めて）という要望も出ていた。インポートできる量を増やすことは、その対応の一つとして位置づけられた。1 つのプロジェクトで扱うカードの数は、1 万件程度までを想定していた
- 画面を開いたまま取り込みの完了を待つ作りでは、大きなファイルに耐えられない。そこで、取り込みをサーバー側で順番に進め、研究者は待たずにほかの作業に戻れるようにする方針にした

## 決めたこと

- インポートは受け付けた後、サーバーで定期的に起動する処理がバックグラウンドで取り込む
- 取り込んでいる間、そのプロジェクトはカードの一覧の代わりにインポート中の表示を出し、カードを操作させない。ほかのプロジェクトは普段どおり操作できる
- インポート中の画面から、プロジェクト一覧に戻れるようにする
- 取り込みの結果（成功・エラー）はインポート履歴として残し、エラーのときは後から確かめられるようにする
- 行や列が多いファイルでも取り込めるよう、データベースへの書き込みを分けて行う
- アップロードできるファイルの大きさの目安を、インポートの画面に示す
- 取り込みのキャンセルは行わない
