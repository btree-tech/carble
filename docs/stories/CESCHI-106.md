# CESCHI-106 大きなファイルのインポートが終わらない

## 背景（なぜ）

- 研究者が、ほかの人が作ったデータを自分の作業しやすい形に直すために、エクスポートしたファイルを表計算ソフトで並べ替え・ID の振り直しなどをして、Carble に取り込み直そうとした
- ところが、画像を含む ZIP ファイルを取り込むと、画面が読み込み中のまま進まなくなり、画面を離れるしかなかった。プロジェクトは作られていたが、その後もしばらく操作できなかった
- 調べると、取り込みの処理に時間がかかり、サーバーが応答を待つ時間を超えて接続が切れていた。数千件（5000 件を超える）のデータを取り込むと、エラーになることも分かった
- 研究者からは、エクスポートとインポートが手軽にできるなら、細かいデータの操作は表計算ソフトで行うという役割分担もありうる、という考えが出された
- 対応として、プロジェクトのコピー機能や、並び順を変える機能を別に用意する案も挙がったが、大きなデータを取り込めるようにするには、取り込みを画面の操作とは切り離して、サーバーの裏側（バックグラウンド）で進めるのが望ましいと判断した

## 決めたこと

- インポートを、画面からの要求の中で処理しきるのではなく、バックグラウンドで実行する。実装は CESCHI-156 で行った
- 取り込みの結果（画像ファイルが見つからないなどの確認の結果）は、後から利用者に伝えられるように残す
