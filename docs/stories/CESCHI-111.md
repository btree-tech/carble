# CESCHI-111 カードを複製して新しいカードを作る

## 背景（なぜ）

- 課題では、カードを複製して新しいカードを作れるようにすることを求めている
- 最初の版を試しに使った研究者から、同じような項目を持つカードを複製して作りたい、カードの画面で複製できれば表の画面に戻らずに済む、という意見が出ていた（CESCHI-85 の試用の振り返り）
- 実装を確かめた際、カード入力ビューで複製しても画面に変化が無く、複製できたのか分かりにくいことが分かった

## 決めたこと

- カード入力ビューとテーブルビューに、カードを複製する操作を加える
- 複製した後は、一定時間で消える通知で、複製したことを知らせる
