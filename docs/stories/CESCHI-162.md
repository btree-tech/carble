# CESCHI-162 最後のカードで「次」の代わりにカードの追加ボタンを出す

## 背景（なぜ）

- 研究者からの要望で、カード入力ビューの「次のカード」の位置に、次のカードが無い場合はカードを追加するボタンを表示してほしい、というもの
- 課題には、要望の理由は書かれていない

## 決めたこと

- 次のカードが無い場合、「次」の位置にカードを追加するボタンを表示する
- 押すと空のカードを追加し、追加したカードのカード入力ビューに移る
- 追加したことが分かるよう、通知を表示する。通知とボタンが重ならないよう、ボタンの位置を調整する

## 反映した仕様

- [カード入力ビュー](../product-spec/pages/card-view.md)

## 関連する課題

- CESCHI-163: 画面とボタンの名前を分かりやすくする（「カード入力ビュー」「次」「追加」などへの変更）
