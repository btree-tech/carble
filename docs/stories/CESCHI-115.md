# CESCHI-115 テーブルビューをキーワードで絞り込む

## 背景（なぜ）

- 課題では、キーワードを入れて、そのキーワードを含むカードだけを表示できるようにすることを求めている。なぜ求めたのかは、課題に書かれていない
- 実装を確かめた際、絞り込んでいるのかどうかが画面から分かりにくいこと、カードが増えると表示に時間がかかることが気になった。そこで、絞り込み中であることが分かる件数の表示を加え、絞り込みと並び替えをサーバー側で行うことにした

## 決めたこと

- 検索のキーワードの入力欄を置き、いずれかの値にキーワードを部分一致で含むカードだけを表示する
- 絞り込んでいないときは全件数を、絞り込み中は「表示件数 / 全件数」を表示し、違いが分かるようにする。カードの追加・削除・複製のたびに件数を更新する
- 絞り込みと並び替えは、サーバー側で行う
- 検索した状態でほかのプロジェクトに移ったとき、検索欄の表示と実際の絞り込みの条件が食い違わないようにする
