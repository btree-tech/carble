# CESCHI-174 カードを別のプロジェクトへ複製し、まとめて削除する

## 背景（なぜ）

- 研究者から「カード群を再編して、新しいプロジェクトを作りたい」という要望があった。この課題は、そのうちの別のプロジェクトへの複製と、まとめての削除を担う
- 要望には、カードの一部を除いたり順番を入れ替えたりして新しいプロジェクトを作りたい、既存のプロジェクトにもカードを加えたい、という希望が含まれていた。要望の優先度を確かめた際にも、プロジェクトをまたいだ複製が求められた
- 仕様の検討で、カードを集めるための専用の作業場所は設けず、別のプロジェクトにカードを複製し、グリッドビューで並べて再編する方針にした。そのため、カードを選んで別のプロジェクトへ複製する操作が必要になった

## 決めたこと

- 複数のカードを選び、まとめて削除・複製できるようにする
- 複製先は、既存の別のプロジェクトか、新しく作るプロジェクトから選べる
- 複製した後は、複製先のプロジェクトに移る
- インポート中のプロジェクトは、複製先に選べないようにする
- テーブルビューに加え、グリッドビューからも同じ操作ができるようにする
