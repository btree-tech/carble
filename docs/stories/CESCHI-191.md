# CESCHI-191 インポートの完了を自動で確かめ、ファイルからプロジェクトを作れるようにする

## 背景（なぜ）

- インポートは時間がかかるため、終わったかどうかを確かめるには、利用者がインポート中の画面を自分で再読み込みする必要があり、手間だった
- 新しいプロジェクトを作ると、初期の項目（みだし・メモ）が入る。そこからファイルをインポートすると、ファイルに無い不要な項目が残ってしまう。手元のファイルの内容のままでプロジェクトを作りたいという要望があった

## 決めたこと

- インポート中の画面で、インポートが終わったかを一定の間隔（30 秒）で自動で確かめる
- プロジェクト一覧に、ファイルをインポートしてプロジェクトを作る入口を設ける。ここから作るプロジェクトには、初期の項目を作らない
- ファイルから作ったプロジェクトは、ファイル名をプロジェクト名にする。名前の無いプロジェクトばかりが増えて見分けにくかったため、開発中に追加した
