# CESCHI-227 共同編集で、意図せずカードの内容を失わないようにする

## 背景（なぜ）

- 招待されたユーザーが、自分の持つ別のプロジェクトを、招待されたプロジェクトにインポートで合流させようとしたところ、合流先のカードが同じ ID のカードとして上書きされてしまった
- 閲覧だけを許す権限は、公開はできないが特定の研究者には見せたい場合のために要望として挙がっていたが、優先度は高くないとされ、まだ設けていない
- 今のメンバーの権限には段階が無い（閲覧だけの権限などが無い）。招待された人が誤ってインポートで一括の上書きをしてしまう危険を避けたほうが、共同作業を怖がらずに始められると、研究者と話して判断した
- プロジェクト一覧で、招待されたプロジェクトと自分のプロジェクトの区別がつかなかった
- 招待して共同編集を始める前に、元の状態を残しておけるよう、バックアップ（エクスポート）を勧めたいという要望があった

## 決めたこと

- インポートは、プロジェクトのオーナーだけができる。エクスポートは、編集者も引き続きできる
- インポートは、カードを追加するのを基本とする。同じ ID のカードを上書きするのは、オーナーがひと手間かけて明示的に選んだときだけとし、選んだときにはバックアップを勧める（詳細は CESCHI-232 に分けた）
- プロジェクト一覧の各プロジェクトに、オーナーの名前を表示する
- 招待の画面に、招待の前にエクスポートでバックアップを残すことを勧める案内を、常に表示する。招待のたびに確認を出す案や、最初の招待のときだけ出す案も考えたが、常に表示する形に決めた
