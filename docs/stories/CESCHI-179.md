# CESCHI-179 グリッドビュー以外でも、カードを並び順どおりに扱う

## 背景（なぜ）

- グリッドビューで、カードをドラッグして並べ替えられるようにした（CESCHI-173）。その並び順は、プロジェクトのメンバー全員に共通の値とした。1 つのプロジェクトを共同で整理するため、人ごとに順番が違うと混乱するからである
- カード群の再編の要望について優先度を確かめた際、少なくともカードの ID と並び順を分けることが求められていた
- テーブルビューでほかの項目で並び替えると、グリッドビューと同じ順番に戻す方法がなかった。そこで、テーブルビューでも並び順を表示し、並び順で並び替えられることが最低限必要と判断した
- インポート・エクスポート・印刷など、グリッドビュー以外の機能でも、並び順をそろえる必要があった。インポートを優先して対応した

## 決めたこと

- インポートで新しく追加するカードは、ファイルの行の順に並び順を振る
- エクスポートは、並び順の順に書き出す
- テーブルビューの初期の並び替えを並び順にし、並び順の列を表示する。ID と隣り合うと紛らわしいため、並び順の列は左端に置く
- グリッドビューからテーブルビューに移ったときは、並び替えた後の並び順をすぐに表示する
- カード入力ビューにも並び順を表示する
- カード印刷ビューは並び順の順に並べる
