# CESCHI-161 入力中に文字がおかしくなり、打ち込みにくい

## 背景（なぜ）

- 研究者が項目に直接文字を打ち込んでいると、入力の速さに画面が追いつかず、漢字の変換がおかしくなった。変換した後に元のひらがなが残ったり、変換しなくてもひらがなが勝手に繰り返されたりして、打ち込みにくかった
- 開発者が通信を遅くして試すと同じ現象が起き、入力の途中で行われる自動保存と、画面の入力欄の更新が食い違うことが原因と見られた
- 早く直してほしいという要望だったため、まず自動保存の間隔を延ばして症状を和らげ、そのうえで原因と思われる箇所を直した

## 決めたこと

- 自動保存の結果で入力中の内容が上書きされないよう、入力欄の扱いを直す
- 通信が遅い場合でも、入力と保存の内容が食い違わないことを確かめた
- 自動保存は、入力が止まってから 1 秒後のままとする
