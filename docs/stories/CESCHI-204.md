# CESCHI-204 Google アカウントでユーザー登録し、自分のプロジェクトだけを表示する

## 背景（なぜ）

- 研究者が、誰でもユーザー登録するだけで Carble を使い始められるようにしたいという要望があった
- 要望を整理する中で、誰でも使えるように公開する場合、ログインした人ごとに、自分が扱えるプロジェクトだけが並ぶホームを持つ形になるか、という問いが出ていた。1 人が作れるプロジェクトの数に上限を設けるべきかも論点になった
- 研究データは、ほかの利用者から見えると困る。これまでは、利用者ごとにシステムを分け、それぞれ 1 つのパスワードで入る簡易な形で使っていた。目指していたのは、1 つのシステムで複数のユーザーを管理し、誰がどのプロジェクトを扱えるかを決められる形であり、この課題でその土台を作った
- 後で共同編集の相手を招待できるように、ユーザーには他の人から指定できるユーザーIDを持たせることにした。名前は、今後、作業した人として表示するために必須とした

## 決めたこと

- ログインは Google アカウントで行う。Carble 独自のパスワードは持たない
- 初回のログインでは、ユーザーID（ほかの人と重ならないもの）と名前を入力して登録する
- 登録したユーザーIDと名前は、後から設定画面で変更できる
- プロジェクト一覧と、カードの複製先の一覧には、自分が扱えるプロジェクトだけを表示する
- ユーザーを削除しても、そのユーザーのプロジェクトは消さない
- 利用者ごとにシステムを分けてパスワードで入る、以前の仕組みはやめた
- メールアドレスはできれば保存しない方針だったが、Google でのログインではメールアドレスを受け取る必要があり、使っている認証の仕組みでも保存を外せないため、保存する前提とした
