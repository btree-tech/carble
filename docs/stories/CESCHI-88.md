# CESCHI-88 研究データをためるツールを実装する

## 背景（なぜ）

- CESCHI-86 で決めた画面仕様をもとに、最初の版を作った
- 保存のしかたは、画面ごとに動きがそろっていないと分かりにくい。また、入力中に画面を閉じて内容を失うのは避けたい。そこで保存のしかたをそろえることにした
- 研究者は、既にあるデータを表計算ソフトで持っている。また、カードには画像が付く。そのため、表のデータと画像をまとめて取り込み・書き出しできる必要があった
- 試しに使ってみると、表で隠した項目がカードの画面には出たままになるなど、使いにくい点が見つかった

## 決めたこと

- 保存は、全体として入力したらすぐ保存する方針にする
- カードの番号は、プロジェクトの中の連番にして、利用者が見分けられるようにする。カードを消して番号が飛んでも構わない
- プロジェクトの最終更新日時は、カードの値の変更だけでなく、カードの削除や項目の変更でも更新する
- インポートは、表計算のファイル・CSV、または画像を含めた ZIP を受け付ける
  - 番号の列に既にあるカードの番号があれば、そのカードを上書きする。番号が空なら新しいカードを作る
  - 取り込むファイルに無い項目は、消さずに残す（今の表とつなぎ合わせる）
  - 同じ名前の項目が複数あれば、全部を同じ値で上書きする
- エクスポートは、表計算のファイルと画像をまとめた ZIP にする。書き出したファイルは、そのまま取り込み直せる
- 印刷の画面だけで項目の表示・非表示を切り替えられるようにする。初期の状態は表の設定に合わせ、切り替えは保存しない
- 表の行に画像が付いていれば、アイコンを出す
- 表で隠した項目は、カードの画面でも隠す
- プロジェクトを消す前に、確認を出す
