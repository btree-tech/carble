# プロジェクト一覧（トップ）

仕様: [pages/project-list.md](/docs/product-spec/pages/project-list.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-PG-PLIST-US1 | 研究者が、自分が閲覧できるプロジェクトだけを一覧することで、目的のプロジェクトにすぐ移りたい 研究者が、各プロジェクトのオーナー名を見ることで、自分のプロジェクトと招待されたプロジェクトを見分けたい | ブラウザ E2E |
| TC-PG-PLIST-US2 | 招待されたユーザーが、プロジェクト一覧で招待に気づき、承認または拒否したい | ブラウザ E2E |
| TC-PG-PLIST-US3 | 研究者が、手元の表計算のファイルからプロジェクトを作ることで、既存のデータをそのまま Carble に移したい 研究者が、初期の項目（みだし・メモ）を作らずにインポートすることで、不要な項目を増やさないようにしたい | ブラウザ E2E |

## テスト設計（外部仕様）

### ヘッダー

| ID | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|
| TC-PG-PLIST-HDR1 |  | ロゴと、ログインしているユーザーの名前のボタンを表示する | ブラウザ E2E |
| TC-PG-PLIST-HDR2 | 名前のボタンを押すと | 「設定」「ログアウト」のメニューを開く | ブラウザ E2E |
| TC-PG-PLIST-HDR3 | 名前のボタンを押すと → 「設定」を選ぶと | 設定（ユーザー）に遷移する | ブラウザ E2E |
| TC-PG-PLIST-HDR4 | 名前のボタンを押すと → 「ログアウト」を選ぶと | ログアウトしてログイン画面に遷移する | ブラウザ E2E |

### 招待の通知

| ID | 前提（WHERE） | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|---|
| TC-PG-PLIST-INV1 | 招待されているプロジェクトがある場合 |  | プロジェクトごとに「「（プロジェクト名）」に招待されています」と、「承認」「拒否」ボタンを表示する | ブラウザ E2E |
| TC-PG-PLIST-INV2 | 招待されているプロジェクトがある場合 |  | 最終更新日時の新しいプロジェクトから順に並べる | ブラウザ E2E |
| TC-PG-PLIST-INV3 | 招待されているプロジェクトがある場合 | 「承認」を押すと | そのプロジェクトのメンバー（編集者）になり、通知を消してプロジェクトの一覧に加える | ブラウザ E2E |
| TC-PG-PLIST-INV4 | 招待されているプロジェクトがある場合 | 「拒否」を押すと | 招待を取り消し、通知を消す | ブラウザ E2E |
