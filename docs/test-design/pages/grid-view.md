# グリッドビュー

仕様: [pages/grid-view.md](/docs/product-spec/pages/grid-view.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-PG-GRID-US1 | 研究者が、カードを画像付きのタイルで並べ、ドラッグで並び替えることで、カード群を再編したい 研究者が、並び替えたカードを選んで別のプロジェクトに複製することで、再編したカード群から新しいプロジェクトを作りたい | ブラウザ E2E |

## テスト設計（外部仕様）

### ヘッダー

| ID | 前提（WHERE） | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|---|
| TC-PG-GRID-HDR1 |  |  | プロジェクト名、「テーブルビュー」ボタン、保存状態のアイコンを表示する | ブラウザ E2E |
| TC-PG-GRID-HDR2 |  | 「テーブルビュー」を押すと | テーブルビューに遷移する | ブラウザ E2E |
| TC-PG-GRID-HDR3 | スマホ幅の場合 |  | 「テーブルビュー」ボタンの文言を省いてアイコンだけにする | ブラウザ E2E |
| TC-PG-GRID-HDR4 |  |  | 保存状態のアイコンは、並び替えの保存の状態を表す（画面共通） | ブラウザ E2E |

### カードの表示

| ID | 前提（WHERE） | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|---|
| TC-PG-GRID-VIEW1 |  |  | カードを並び順の昇順に、タイルで並べて表示する | ブラウザ E2E |
| TC-PG-GRID-VIEW2 |  |  | 各タイルに「表示項目1」「表示項目2」で選んだ内容と、「カード入力」ボタンを表示する | ブラウザ E2E |
| TC-PG-GRID-VIEW3 | 選んだ内容が画像の場合 |  | カードの 1 枚目の画像を表示する | ブラウザ E2E |
| TC-PG-GRID-VIEW4 | 選んだ内容が ID の場合 |  | 「ID: （ID）」と表示する | ブラウザ E2E |
| TC-PG-GRID-VIEW5 | 選んだ内容が項目の場合 |  | その項目の値を表示する | ブラウザ E2E |
| TC-PG-GRID-VIEW6 |  |  | 「表示項目1」「表示項目2」の選択欄を表示する | ブラウザ E2E |
| TC-PG-GRID-VIEW7 |  |  | 選べるのは「画像」「ID」と、すべての項目（非表示の項目も含む）とする | ブラウザ E2E |
| TC-PG-GRID-VIEW8 |  |  | 初期値は「表示項目1」が画像、「表示項目2」が ID とする | ブラウザ E2E |
| TC-PG-GRID-VIEW9 |  |  | 選んだ内容は、同じプロジェクトの画面を移っても保持する。保存はせず、ブラウザを再読み込みすると初期値に戻る | ブラウザ E2E |
| TC-PG-GRID-VIEW10 |  | 「カード入力」を押すと | そのカードのカード入力ビューに遷移する | ブラウザ E2E |

### 並び替え

| ID | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|
| TC-PG-GRID-SORT1 | タイルをドラッグして別の位置に置くと | 表示どおりの順に並び順を 1 から振り直して保存する | ブラウザ E2E |

### 選択

| ID | 区間（WHILE） | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|---|
| TC-PG-GRID-SEL1 |  | 各タイルにマウスを乗せると | 選択のチェックボックスを表示する | ブラウザ E2E |
| TC-PG-GRID-SEL2 | 1 件以上選んでいる間は | 各タイルにマウスを乗せると | すべてのタイルにチェックボックスを表示し、選んだタイルに色を付ける | ブラウザ E2E |
| TC-PG-GRID-SEL3 |  | タイルの「カード入力」以外の場所を押すと | そのタイルの選択を切り替える | ブラウザ E2E |
| TC-PG-GRID-SEL4 | Shift キーを押している間は |  | 前に選んだタイルとの間のタイルをまとめて選ぶ（選択を外したときは、まとめて外す） | ブラウザ E2E |
| TC-PG-GRID-SEL5 |  |  | 選んだカードの一括操作は カードの選択と一括操作 を参照 | ブラウザ E2E |
