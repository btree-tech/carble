# 設定（ユーザー）

仕様: [pages/user-settings.md](/docs/product-spec/pages/user-settings.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-PG-USERSET-US1 | 研究者が、登録したユーザーIDと名前を後から変更することで、共同作業の相手に分かりやすい表示にしたい | ブラウザ E2E |
| TC-PG-USERSET-US2 | 研究者が、使わなくなったユーザーデータを自分で削除することで、個人の情報を残さないようにしたい | ブラウザ E2E |

## テスト設計（外部仕様）

### ユーザーIDと名前の変更

| ID | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|
| TC-PG-USERSET-EDIT1 |  | ユーザー登録と同じ入力欄・確認・「保存」ボタンを表示する | ブラウザ E2E |
| TC-PG-USERSET-EDIT2 |  | 自分の今のユーザーID は「既に使われています」としない | ブラウザ E2E |
| TC-PG-USERSET-EDIT3 |  | ほかの画面へのリンク（プロジェクト一覧へ戻るリンクなど）は表示しない。保存するか、ブラウザの「戻る」で離れる | ブラウザ E2E |
| TC-PG-USERSET-EDIT4 | 「保存」を押すと | ユーザーIDと名前を保存し、プロジェクト一覧に遷移する | ブラウザ E2E |

### ユーザーデータの削除

| ID | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|
| TC-PG-USERSET-DEL1 |  | 入力欄の下に、区切り線をはさんで「ユーザーデータを削除」ボタンを表示する | ブラウザ E2E |
| TC-PG-USERSET-DEL2 | 「ユーザーデータを削除」を押すと | 「本当に削除しますか？」と確認する | ブラウザ E2E |
| TC-PG-USERSET-DEL3 | 「ユーザーデータを削除」を押すと → 確認すると | ユーザーを削除してログアウトし、ログイン画面に遷移する | ブラウザ E2E |
| TC-PG-USERSET-DEL4 | 「ユーザーデータを削除」を押すと → 確認すると | 参加していたプロジェクトのメンバーからも外れる。受けていた招待も消える | ブラウザ E2E |
| TC-PG-USERSET-DEL5 | 「ユーザーデータを削除」を押すと → 確認をキャンセルすると | 何もしない | ブラウザ E2E |
