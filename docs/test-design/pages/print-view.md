# カード印刷ビュー

仕様: [pages/print-view.md](/docs/product-spec/pages/print-view.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-PG-PRINT-US1 | 研究者が、カードを紙に印刷することで、資料と一緒に保管したり、会合で配ったりしたい 研究者が、印刷したカードの QR コードを後でスキャンすることで、紙のカードからデータのカードにたどり着きたい | ブラウザ E2E |
| TC-PG-PRINT-US2 | 研究者が、印刷のレイアウトと載せる項目・画像の枚数を選ぶことで、資料に合った体裁で印刷したい 研究者が、別のカードに移っても印刷の設定を保つことで、1 枚ずつ設定し直さずに済むようにしたい | ブラウザ E2E |
| TC-PG-PRINT-US3 | 研究者が、A4 用紙 1 枚に 2 枚のカードを、ちょうど半分ずつに印刷したい | ブラウザ E2E |

| TC-PG-PRINT-HDR2 |  | 「テーブルビュー」を押すと | テーブルビューに遷移する | ブラウザ E2E |
| TC-PG-PRINT-HDR3 | 1 枚のカードの印刷の場合 |  | 「カード入力ビュー」ボタンも表示する | ブラウザ E2E |

| TC-PG-PRINT-HDR5 | 1 枚のカードの印刷の場合 |  | 「テーブルビュー」「カード入力ビュー」は、カード入力ビューから引き継いだ並び替えと検索の条件を引き継ぐ | ブラウザ E2E |
| TC-PG-PRINT-HDR6 | スマホ幅の場合 |  | ヘッダーのボタンの文言を省いてアイコンだけにする | ブラウザ E2E |

### 設定

| ID | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|
| TC-PG-PRINT-CONF1 |  | 「レイアウト」で「パターン1」「パターン2」「パターン3」から選ぶ。初期値は「パターン1」とする | ブラウザ E2E |
| TC-PG-PRINT-CONF2 |  | 固定領域ごとに、表示する内容を「画像」「ID」と、すべての項目から 1 つ選ぶ | ブラウザ E2E |
| TC-PG-PRINT-CONF3 |  | 初期値は、固定領域1 が画像、固定領域2 が最初に表示している項目（表示している項目が無ければ ID）とする | ブラウザ E2E |
| TC-PG-PRINT-CONF4 | 固定領域で内容を選ぶと | その内容をこの固定領域に移し、それまでこの固定領域で選んでいた内容は任意項目に移す | ブラウザ E2E |
| TC-PG-PRINT-CONF5 | 固定領域で内容を選ぶと → 別の固定領域で選んでいる内容を選ぶと | もとの固定領域は空になる | ブラウザ E2E |
| TC-PG-PRINT-CONF6 | 固定領域の数が少ないレイアウトに変えると | あふれた内容を任意項目に移す | ブラウザ E2E |
| TC-PG-PRINT-CONF7 | 固定領域の数が多いレイアウトに変えると | 増えた固定領域に任意項目の内容を 1 つ移す | ブラウザ E2E |
| TC-PG-PRINT-CONF8 |  | 「任意項目」に、固定領域で選んでいない内容（画像・ID・項目）を一覧し、それぞれの表示／非表示を切り替える | ブラウザ E2E |
| TC-PG-PRINT-CONF9 |  | 初期値は、非表示の項目は非表示、それ以外（ID・表示している項目）は表示とする | ブラウザ E2E |
| TC-PG-PRINT-CONF10 |  | 固定領域から任意項目に移した内容は、表示とする | ブラウザ E2E |
| TC-PG-PRINT-CONF11 |  | 「表示画像枚数」で、カードに載せる画像の枚数を選ぶ。0 はすべての画像とする（初期値 0） | ブラウザ E2E |
| TC-PG-PRINT-CONF12 |  | 「一行あたりの表示画像枚数」で、画像を横に並べる枚数を選ぶ。0 は載せる画像をすべて 1 行に並べる（初期値 0） | ブラウザ E2E |
| TC-PG-PRINT-CONF13 |  | 設定は、同じプロジェクトのカード印刷ビューを移っても保持する | ブラウザ E2E |
| TC-PG-PRINT-CONF14 |  | 設定は保存しない。ブラウザを再読み込みすると初期値に戻る | ブラウザ E2E |

| ID | レイアウト | 固定領域 | 固定領域でない領域（任意項目） | 層 |
|---|---|---|---|---|
| TC-PG-PRINT-CONF15 | パターン1 | 固定領域1（左上の大きい領域）、固定領域2（下段の全幅） | 右上 | ブラウザ E2E |
| TC-PG-PRINT-CONF16 | パターン2 | 固定領域1（左） | 右 | ブラウザ E2E |
| TC-PG-PRINT-CONF17 | パターン3 | 固定領域1（左上）、固定領域2（左下） | 右（全高） | ブラウザ E2E |

### 印刷

| ID | 前提（WHERE） | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|---|
| TC-PG-PRINT-PRT1 |  | 「印刷」を押すと | ブラウザの印刷のダイアログを開く | ブラウザ E2E |
| TC-PG-PRINT-PRT2 |  | 「印刷」を押すと | A4 縦の用紙 1 枚に、カードを 2 枚ずつ、上下半分に分けて印刷する | ブラウザ E2E |
| TC-PG-PRINT-PRT3 | カードが奇数枚の場合 | 「印刷」を押すと | 最後の用紙には上半分だけに印刷する | ブラウザ E2E |
| TC-PG-PRINT-PRT4 |  | 「印刷」を押すと | 画面のヘッダーと設定は印刷しない | ブラウザ E2E |

- `対象外` `手段なし` TC-PG-PRINT-PRT1: 印刷のダイアログはブラウザが開く OS の画面で、ヘッドレスのブラウザでは開かない（製品のコードを置き換えて window.print を見張ることもしない）。印刷する内容（A4 縦に 2 枚ずつ・ヘッダーと設定を印刷しない）は、子の項目として print-view.spec.ts で印刷用のメディアと PDF で確かめる
