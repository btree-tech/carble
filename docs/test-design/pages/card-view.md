# カード入力ビュー

仕様: [pages/card-view.md](/docs/product-spec/pages/card-view.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-PG-CARD-US1 | 研究者が、1 枚のカードの項目と画像をまとめて見ながら入力することで、表では読みにくい長い文章を読み書きし、添えた画像を見ながら書き写したい | ブラウザ E2E |
| TC-PG-CARD-US2 | 研究者が、前後のカードへ移ったり、最後のカードからそのまま次のカードを追加したりすることで、手を止めずに入力を続けたい | ブラウザ E2E |
| TC-PG-CARD-US3 | 研究者が、書き込んだ紙のカードやメモ・資料の写真をカードに添えることで、紙の記録とデータを一緒に残したい | ブラウザ E2E |
| TC-PG-CARD-US4 | 研究者が、カード入力ビューからそのカードだけを印刷することで、1 枚ずつ確認や配布をしたい | ブラウザ E2E |

| ID | メニュー | 動作 | 層 |
|---|---|---|---|
| TC-PG-CARD-MENU2 | 直下に複製 | このカードを複製してすぐ下に置き、「複製しました」と表示し、複製したカードのカード入力ビューに遷移する | ブラウザ E2E |

- `対象外` `乖離` TC-PG-CARD-MENU7: docs/ISSUES.md「カード入力ビューでカードを削除すると次のカードに遷移しない」。次のカードが無いときにテーブルビューに遷移することは tests/e2e/specs/pages/card-view.spec.ts の削除のテストで、今の挙動は同じファイルの【既知の問題】のテストで確かめる
