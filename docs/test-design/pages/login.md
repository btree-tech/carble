# ログイン

仕様: [pages/login.md](/docs/product-spec/pages/login.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-PG-LOGIN-US1 | 研究者が、Google アカウントでログインすることで、新しいパスワードを覚えずに使い始めたい 運営者が、パスワードを預からずに済むようにしたい | ブラウザ E2E |

- `対象外` `手段なし` TC-PG-LOGIN-US1: Google のログイン画面は外部のサービスで、テストから通せない（E2E は DB にログイン状態を作ってログインする）。ログイン後の流れは TC-PG-REGISTER-US1・TC-FT-ROLES-US1 のテストで確かめる。Google でログインする流れは、本番の環境で人が確かめる

## テスト設計（外部仕様）

| ID | 前提（WHERE） | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|---|
| TC-PG-LOGIN-GEN1 |  |  | ロゴと「Googleでログイン」ボタンを表示する | ブラウザ E2E |
| TC-PG-LOGIN-GEN2 |  | 「Googleでログイン」を押すと | Google のログイン画面に遷移する | ブラウザ E2E |
| TC-PG-LOGIN-GEN3 |  | 「Googleでログイン」を押すと → 初めてログインすると | ユーザー登録に遷移する | ブラウザ E2E |
| TC-PG-LOGIN-GEN4 |  | 「Googleでログイン」を押すと → 登録済みのユーザーがログインすると | プロジェクト一覧に遷移する | ブラウザ E2E |
| TC-PG-LOGIN-GEN5 | ユーザーID をまだ登録していない場合 | 「Googleでログイン」を押すと → 登録済みのユーザーがログインすると | ユーザー登録に遷移する（ロールと権限） | ブラウザ E2E |
| TC-PG-LOGIN-GEN6 | ログインしている場合も |  | ログイン画面を表示する。プロジェクト一覧へは遷移しない | ブラウザ E2E |
| TC-PG-LOGIN-GEN7 |  | プロジェクト一覧のユーザーメニューで「ログアウト」を選ぶと | ログアウトしてログイン画面に戻る | ブラウザ E2E |
