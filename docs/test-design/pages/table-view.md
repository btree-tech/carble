# テーブルビュー（プロジェクト詳細・カード一覧）

仕様: [pages/table-view.md](/docs/product-spec/pages/table-view.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-PG-TABLE-US1 | 研究者が、カードを表の形で一覧し、セルに直接入力することで、表計算ソフトのように素早くデータを蓄積したい 研究者が、入力しながら打ち込みにくさを感じずに入力したい | ブラウザ E2E |
| TC-PG-TABLE-US2 | 研究者が、カードを表の形で一覧し、セルに直接入力することで、表計算ソフトのように素早くデータを蓄積したい 研究者が、ブラウザの幅いっぱいに表を広げることで、多くの項目を一度に見たい | ブラウザ E2E |
| TC-PG-TABLE-US3 | 研究者が、項目で並び替えたりキーワードで絞り込んだりすることで、目的のカードを探したい | ブラウザ E2E |
| TC-PG-TABLE-US4 | 研究者が、グリッドビューやインポートで決めた並び順でカードを見ることで、資料の順番どおりに作業したい | ブラウザ E2E |
| TC-PG-TABLE-US5 | 研究者が、プロジェクトに合わせて項目を追加・編集・非表示・並び替えすることで、扱う資料に合った表にしたい | ブラウザ E2E |
| TC-PG-TABLE-US6 | 研究者が、削除の前に確認されることで、誤ってデータを消さないようにしたい | ブラウザ E2E |
