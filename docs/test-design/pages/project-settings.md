## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-PG-PSET-US1 | メンバーが、プロジェクトのデータをファイルに書き出すことで、手元にバックアップを残したり、表計算ソフトで扱ったりしたい | ブラウザ E2E |
| TC-PG-PSET-US2 | オーナーが、表計算のファイルからカードを取り込むことで、既存のデータをまとめて登録・更新したい オーナーが、上書きを明示的に選び、その前にバックアップを促されることで、意図せずカードの内容を失わないようにしたい | ブラウザ E2E |
| TC-PG-PSET-US3 | オーナーが、ユーザーIDを入力して他のユーザーを招待することで、共同で編集したい オーナーが、招待の前にバックアップを促されることで、共同編集を始める前の状態を残したい | ブラウザ E2E |
| TC-PG-PSET-US4 | オーナーが、設定の画面をほかの画面と同じく左寄せで見ることで、画面を移っても違和感なく使いたい | ブラウザ E2E |

- `対象外` `乖離` TC-PG-PSET-US1: エクスポートは Node 24 で失敗する（docs/ISSUES.md「エクスポートが失敗する」）。今の挙動は tests/e2e/specs/features/import-export.spec.ts の【既知の問題】のテストで確かめる
- `対象外` `手段なし` TC-PG-PSET-US4: 左寄せで読みやすいかは見た目の判断で、自動テストで決められない。画面を開いて人が確かめる
