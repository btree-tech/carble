# カードの選択と一括操作

仕様: [features/card-selection.md](/docs/product-spec/features/card-selection.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-FT-SELECT-US1 | 研究者が、複数のカードを選んでまとめて削除・複製することで、カード群の整理や再編を手早く行いたい | ブラウザ E2E |

## テスト設計（外部仕様）

### 選択

| ID | 区間（WHILE） | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|---|
| TC-FT-SELECT-SEL1 |  |  | カードごとに選択のチェックボックスを表示する（グリッドビューでの表示は グリッドビュー を参照） | ブラウザ E2E |
| TC-FT-SELECT-SEL2 |  |  | テーブルビューの見出しに、すべてのカードを選ぶチェックボックスを表示する | ブラウザ E2E |
| TC-FT-SELECT-SEL3 |  | 見出しのチェックボックスを選ぶと | 表示しているすべてのカードを選ぶ | ブラウザ E2E |
| TC-FT-SELECT-SEL4 |  | 1 件以上選んでいるときに見出しのチェックボックスを押すと | 選択をすべて外す | ブラウザ E2E |
| TC-FT-SELECT-SEL5 | 一部のカードだけを選んでいる間は |  | 見出しのチェックボックスを「一部選択」の表示にする | ブラウザ E2E |
| TC-FT-SELECT-SEL6 |  | テーブルビューで別の画面に移るか、カードの一覧が変わる（カードの追加・複製・削除、並び替え、検索）と | 選択を外す | ブラウザ E2E |
| TC-FT-SELECT-SEL7 |  |  | グリッドビューでは、別の画面に移っても選択を保つ | ブラウザ E2E |
| TC-FT-SELECT-SEL8 |  | グリッドビューでカードの一覧が変わると | 一覧から無くなったカードだけを選択から外す | ブラウザ E2E |

### 一括操作

| ID | 区間（WHILE） | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|---|
| TC-FT-SELECT-BULK1 | 1 件以上選んでいる間は |  | 「（件数）件選択中」「複製」「削除」のボタンを表示する | ブラウザ E2E |
| TC-FT-SELECT-BULK2 | 1 件以上選んでいる間は | 「（件数）件選択中」を押すと | 選択をすべて外す | ブラウザ E2E |
| TC-FT-SELECT-BULK3 |  | 「複製」を押すと | 複製先のプロジェクトの一覧を開く（カードの複製） | ブラウザ E2E |
| TC-FT-SELECT-BULK4 |  | 「複製」を押すと | 今開いているプロジェクトは一覧に含めない | ブラウザ E2E |
| TC-FT-SELECT-BULK5 |  | 「複製」を押すと → プロジェクトを選ぶと | 選んだカードすべてをそのプロジェクトの末尾に複製し、「複製しました」と表示して、そのプロジェクトのテーブルビューに遷移する | ブラウザ E2E |
| TC-FT-SELECT-BULK6 |  | 「複製」を押すと → 「新しいプロジェクト」を選ぶと | 新しいプロジェクトを作って選んだカードすべてを複製し、「複製しました」と表示して、複製した最初のカードのカード入力ビューに遷移する | ブラウザ E2E |
| TC-FT-SELECT-BULK7 |  | 「削除」を押すと | 「削除してよろしいですか？」と確認する | ブラウザ E2E |
| TC-FT-SELECT-BULK8 |  | 「削除」を押すと → 確認すると | 選んだカードすべてを削除する | ブラウザ E2E |

- `対象外` `乖離` TC-FT-SELECT-BULK6: docs/ISSUES.md「新しいプロジェクトに複製するとプロジェクトを開けない」・knownIssue(SPEC, '「新しいプロジェクト」に複製すると、作ったプロジェクトにオーナーが設定されず、遷移した先は空の画面になる（エラー画面は表示しない）')。今の挙動は tests/e2e/specs/features/card-selection.spec.ts の【既知の問題】【実装との乖離】のテストで確かめる
