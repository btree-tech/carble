# ロールと権限

仕様: [features/roles.md](/docs/product-spec/features/roles.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-FT-ROLES-US1 | 研究者が、Google アカウントでユーザー登録するだけで使い始めることで、誰でも手軽にカードでデータを蓄積したい 研究者が、自分が閲覧できるプロジェクトだけを一覧することで、他の人のデータと混ざらずに作業したい | ブラウザ E2E |
| TC-FT-ROLES-US2 | プロジェクトのオーナーが、他のユーザーをプロジェクトに招待することで、共同でカードを編集したい 招待されたユーザーが、招待を承認または拒否することで、参加するプロジェクトを自分で選びたい | ブラウザ E2E |
| TC-FT-ROLES-US3 | オーナーが、インポートによる一括の上書きを自分だけに限ることで、編集者が誤ってデータを失う心配なく共同作業したい | ブラウザ E2E |

## テスト設計（外部仕様）

| ID | ロール | 説明 | 主な操作 | 層 |
|---|---|---|---|---|
| TC-FT-ROLES-GEN1 | オーナー | プロジェクトを作成したユーザー。プロジェクトに 1 人。プロジェクト一覧の列名は「オーナー」、プロジェクト設定のユーザー管理の「権限」は「管理者」と表示する | 編集者の操作すべて、インポート、ユーザーの招待・削除、プロジェクトの削除 | ブラウザ E2E |
| TC-FT-ROLES-GEN2 | 編集者 | オーナーの招待を承認したユーザー。ユーザー管理の「権限」は空欄 | カード・項目の追加・編集・削除・複製、プロジェクト名の変更、エクスポート、印刷 | ブラウザ E2E |
| TC-FT-ROLES-GEN3 | 招待中のユーザー | オーナーに招待され、まだ承認していないユーザー。ユーザー管理の「ステータス」に「招待中」と表示する | プロジェクト一覧での招待の承認・拒否のみ | ブラウザ E2E |

### ログイン

| ID | 前提（WHERE） | 異常（IF） | 結果 | 層 |
|---|---|---|---|---|
| TC-FT-ROLES-LOGI1 |  |  | ログイン画面以外の画面は、ログインしているユーザーだけが使える | ブラウザ E2E |
| TC-FT-ROLES-LOGI2 |  | ログインせずにログイン画面以外を開いた場合 | ログイン画面に遷移する | ブラウザ E2E |
| TC-FT-ROLES-LOGI3 | ログインしているがユーザーIDを登録していない場合 |  | ログイン画面以外のどの画面を開いてもユーザー登録に遷移する | ブラウザ E2E |

### プロジェクトへのアクセス

| ID | 前提（WHERE） | 異常（IF） | 結果 | 層 |
|---|---|---|---|---|
| TC-FT-ROLES-ACC1 | プロジェクトのメンバーの場合 |  | そのプロジェクトの画面（テーブルビュー・カード入力ビュー・グリッドビュー・カード印刷ビュー・プロジェクト設定）を表示する | ブラウザ E2E |
| TC-FT-ROLES-ACC2 |  | メンバーでないプロジェクトの画面を開いた場合 | エラー画面（404）を表示する | ブラウザ E2E |
| TC-FT-ROLES-ACC3 |  | メンバーでないプロジェクトの画面を開いた場合 | 招待中のユーザーも、承認するまではメンバーでないものとして扱う | ブラウザ E2E |
| TC-FT-ROLES-ACC4 | オーナーの場合 |  | プロジェクト設定に「インポート」「ユーザー管理」「プロジェクト削除」のタブを表示する | ブラウザ E2E |
| TC-FT-ROLES-ACC5 | 編集者の場合 |  | プロジェクト設定には「全般」のタブだけを表示する | ブラウザ E2E |
| TC-FT-ROLES-ACC6 |  |  | オーナーを変えたり、オーナーをプロジェクトから外したりはできない | ブラウザ E2E |
| TC-FT-ROLES-ACC7 |  |  | 編集者は、自分でプロジェクトから抜けられない。外すのはオーナーだけができる | ブラウザ E2E |
