# 画面共通（完了メッセージ・保存状態・エラー画面）

仕様: [features/common-layout.md](/docs/product-spec/features/common-layout.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-FT-LAYOUT-US1 | 研究者が、入力した内容を保存ボタンを押さずに残すことで、画面を閉じても入力を失わないようにしたい 研究者が、保存中・保存済み・失敗を見分けることで、入力が確実に残ったか安心したい | ブラウザ E2E |
| TC-FT-LAYOUT-US2 | 研究者が、操作が終わったことを画面で確かめたい | ブラウザ E2E |

## テスト設計（外部仕様）

### 保存状態のアイコン

| ID | 区間（WHILE） | 操作（WHEN） | 異常（IF） | 結果 | 層 |
|---|---|---|---|---|---|
| TC-FT-LAYOUT-SAVE1 |  |  |  | プロジェクトの画面で入力した値（プロジェクト名・カードの値・並び順）は自動で保存する。保存ボタンは無い | ブラウザ E2E |
| TC-FT-LAYOUT-SAVE2 |  |  |  | ユーザーIDと名前は自動で保存せず、「保存」ボタンで保存する（ユーザー登録・設定（ユーザー）） | ブラウザ E2E |
| TC-FT-LAYOUT-SAVE3 |  |  |  | テーブルビュー・カード入力ビュー・グリッドビューのヘッダーに、保存状態のアイコンを表示する | ブラウザ E2E |
| TC-FT-LAYOUT-SAVE4 | 保存中は |  |  | 回転するアイコンを表示する | ブラウザ E2E |
| TC-FT-LAYOUT-SAVE5 |  | 保存が終わると |  | チェックのアイコンを表示する | ブラウザ E2E |
| TC-FT-LAYOUT-SAVE6 |  |  | 保存に失敗した場合 | 赤いエラーのアイコンを表示する | ブラウザ E2E |

### 完了メッセージ

| ID | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|
| TC-FT-LAYOUT-MSG1 | 次の操作が完了すると | 画面の隅に完了メッセージを表示する | ブラウザ E2E |
| TC-FT-LAYOUT-MSG2 |  | 選択したカードの一括削除・項目の追加・画像の削除など、ほかの操作では完了メッセージを表示しない | ブラウザ E2E |

| ID | 操作 | メッセージ | 層 |
|---|---|---|---|
| TC-FT-LAYOUT-MSG3 | カードの追加 | 「追加しました」 | ブラウザ E2E |
| TC-FT-LAYOUT-MSG4 | カードの複製（選択したカードの複製を含む） | 「複製しました」 | ブラウザ E2E |
| TC-FT-LAYOUT-MSG5 | カードの削除（1 件ずつの削除） | 「削除しました」 | ブラウザ E2E |
| TC-FT-LAYOUT-MSG6 | スキャン（既存のカードに画像を追加） | 「スキャン完了」「ID: （カードのID）のカードに画像を追加しました」 | ブラウザ E2E |
| TC-FT-LAYOUT-MSG7 | スキャン（新しいカードを追加） | 「スキャン完了」「新しいカードを追加しました」 | ブラウザ E2E |
| TC-FT-LAYOUT-MSG8 | プロジェクトの削除 | 「プロジェクトを削除しました」 | ブラウザ E2E |
