# スキャン（QR コード）

仕様: [features/scan.md](/docs/product-spec/features/scan.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-FT-SCAN-US1 | 研究者が、書き込んだ印刷のカードを撮影することで、撮った写真をそのカードに自動で添え、手書きの内容を後で書き写せるようにしたい | ブラウザ E2E |
| TC-FT-SCAN-US2 | 研究者が、資料を撮影するだけで新しいカードを作ることで、写真から記録を始めたい | ブラウザ E2E |

## テスト設計（外部仕様）

| ID | 前提（WHERE） | 区間（WHILE） | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|---|---|
| TC-FT-SCAN-GEN1 |  |  |  | 「スキャン」ボタンを表示する | ブラウザ E2E |
| TC-FT-SCAN-GEN2 | スマホ幅の場合 |  |  | 「スキャン」の文言を省いてアイコンだけにする | ブラウザ E2E |
| TC-FT-SCAN-GEN3 |  |  | 「スキャン」を押すと | 画像を選ぶ画面を開く | ブラウザ E2E |
| TC-FT-SCAN-GEN4 | スマホ・タブレットの場合 |  | 「スキャン」を押すと | カメラを起動して撮影できる | ブラウザ E2E |
| TC-FT-SCAN-GEN5 |  |  | 画像を選ぶと | 画像の中の QR コードを読み取る | ブラウザ E2E |
| TC-FT-SCAN-GEN6 |  | 読み取りと画像の追加の処理中は | 画像を選ぶと | 「スキャン」ボタンに処理中の表示をする | ブラウザ E2E |
| TC-FT-SCAN-GEN7 | カード印刷ビューで印刷したカードの QR コードが写っていて、そのカードを開ける場合 |  | 画像を選ぶと | そのカードに画像を追加し、そのカードのカード入力ビューに遷移して「スキャン完了」「ID: （ID）のカードに画像を追加しました」と表示する | ブラウザ E2E |
| TC-FT-SCAN-GEN8 | QR コードが写っていない、またはカードを特定できない場合 |  | 画像を選ぶと | 開いているプロジェクトの末尾にその画像を持つ新しいカードを作り、そのカードのカード入力ビューに遷移して「スキャン完了」「新しいカードを追加しました」と表示する | ブラウザ E2E |

- `対象外` `手段なし` TC-FT-SCAN-GEN4: カメラの起動は端末の OS が行い、テストのブラウザでは起きない。画像を選ぶ画面が開くことは scan.spec.ts・scan.mobile.spec.ts で確かめる
