# カードの複製

仕様: [features/card-duplicate.md](/docs/product-spec/features/card-duplicate.md)

## テスト設計（ユーザーストーリー）

| ID | ストーリー | 層 |
|---|---|---|
| TC-FT-DUP-US1 | 研究者が、似た内容のカードを複製して作ることで、同じ値を何度も入力せずに済むようにしたい | ブラウザ E2E |
| TC-FT-DUP-US2 | 研究者が、カード群を別のプロジェクトに複製することで、再編したカード群から新しいプロジェクトを作りたい | ブラウザ E2E |
| TC-FT-DUP-US3 | 研究者が、複製元と複製先のカードをたどることで、複製した後のカードの違いを確かめたい | ブラウザ E2E |

## テスト設計（外部仕様）

### 複製の内容

| ID | 結果 | 層 |
|---|---|---|
| TC-FT-DUP-CONT1 | 複製すると、元のカードと同じ値・同じ画像を持つ新しいカードを作る | ブラウザ E2E |
| TC-FT-DUP-CONT2 | 新しいカードの ID は、複製先のプロジェクトのカードの ID の最大値の次から振る | ブラウザ E2E |
| TC-FT-DUP-CONT3 | 画像は、元のカードの画像とは別のファイルとして複製する（元のカードの画像を削除しても、複製したカードの画像は残る） | ブラウザ E2E |
| TC-FT-DUP-CONT4 | 複製したカードは、元のカードを「複製元」として覚える | ブラウザ E2E |
| TC-FT-DUP-CONT5 | 置く位置は次のとおり | ブラウザ E2E |

| ID | 操作 | 置く位置 | 層 |
|---|---|---|---|
| TC-FT-DUP-CONT6 | 直下に複製 | 元のカードのすぐ下。プロジェクトのカードの並び順を 1 から振り直す | ブラウザ E2E |
| TC-FT-DUP-CONT7 | 末尾に複製 | プロジェクトの末尾 | ブラウザ E2E |
| TC-FT-DUP-CONT8 | 別プロジェクトに複製、選択したカードの複製 | 複製先のプロジェクトの末尾。複数のカードは元の並び順の順に置く | ブラウザ E2E |

### 別のプロジェクトへの複製

| ID | 前提（WHERE） | 操作（WHEN） | 結果 | 層 |
|---|---|---|---|---|
| TC-FT-DUP-OTHR1 |  |  | 複製先には、自分がメンバーになっている（招待を受けている途中のものを除く）他のプロジェクトを更新日時の新しい順に一覧し、その下に「新しいプロジェクト」を表示する | ブラウザ E2E |
| TC-FT-DUP-OTHR2 | インポート中のプロジェクトの場合 |  | 「インポート中」と表示し、選べない | ブラウザ E2E |
| TC-FT-DUP-OTHR3 |  |  | 項目は名前で対応づける | ブラウザ E2E |
| TC-FT-DUP-OTHR4 | 複製先に同じ名前の項目が無い場合 |  | その項目を複製先の末尾に追加する | ブラウザ E2E |
| TC-FT-DUP-OTHR5 | 複製先に同じ名前の項目が無い場合 |  | 追加した項目は、複製元で非表示にしていても表示する | ブラウザ E2E |
| TC-FT-DUP-OTHR6 |  | 「新しいプロジェクト」を選ぶと | 「無題のプロジェクト」という名前のプロジェクトを作り、そこに複製する | ブラウザ E2E |

- `対象外` `乖離` TC-FT-DUP-OTHR6: docs/ISSUES.md「新しいプロジェクトに複製するとプロジェクトを開けない」・knownIssue(SPEC, '「新しいプロジェクト」に複製すると、作ったプロジェクトにオーナーが設定されない')。今の挙動は tests/e2e/specs/features/card-duplicate.spec.ts の【既知の問題】【実装との乖離】のテストで確かめる

### 複製元と複製先

| ID | 前提（WHERE） | 操作（WHEN） | 異常（IF） | 結果 | 層 |
|---|---|---|---|---|---|
| TC-FT-DUP-SRC1 | カードに複製元がある場合 |  |  | 「複製元カードを表示」で複製元のカードのカード入力ビューに遷移する | ブラウザ E2E |
| TC-FT-DUP-SRC2 | カードに複製元がある場合 |  |  | 複製元が別のプロジェクトでも遷移する | ブラウザ E2E |
| TC-FT-DUP-SRC3 | カードに複製元がある場合 |  | 複製元のカードが削除されている場合 | 「複製元カードを表示」を選べない | ブラウザ E2E |
| TC-FT-DUP-SRC4 | カードを複製したことがある場合 |  |  | 「複製先カードを表示」で複製先の一覧のダイアログを開く | ブラウザ E2E |
| TC-FT-DUP-SRC5 | カードを複製したことがある場合 |  |  | 一覧には「（プロジェクト名） - ID: （ID）」の形で複製先のカードを表示する | ブラウザ E2E |
| TC-FT-DUP-SRC6 | カードを複製したことがある場合 | 複製先を選ぶと |  | そのカードのカード入力ビューに遷移する | ブラウザ E2E |

| ID | 結果 | 層 |

| TC-FT-DUP-AFTR1 | 複製すると「複製しました」と表示し、次のとおり遷移する | ブラウザ E2E |

| ID | 画面 | 操作 | 遷移先 | 層 |
|---|---|---|---|---|
| TC-FT-DUP-AFTR2 | テーブルビュー | 直下に複製、末尾に複製 | 遷移しない | ブラウザ E2E |
